## 模板代码

### BFS 与 DFS 遍历 (BFS & DFS Traversal)——无权最短路、连通分量、环检测的骨架

图用邻接表（省内存，遍历 O(V+E)）或邻接矩阵（查边 O(1)）存储。日常用 networkx；需要定制遍历逻辑时手写骨架。陷阱：BFS 必须**入队时标记**，出队才标记会重复扩展；递归 DFS 深度大会爆栈。

```python
import networkx as nx
from collections import deque

G = nx.Graph([("A","B"),("A","C"),("B","D"),("C","D"),("D","E")])
print(list(nx.bfs_edges(G, "A")))      # networkx 层序边
print(nx.shortest_path(G, "A", "E"))   # 无权最短路 = BFS 路径
print(list(nx.dfs_edges(G, "A")))      # 深序边

# 手写 BFS 骨架（需要定制逻辑时用）
def bfs_order(adj, src):
    seen = {src}; q = deque([src]); out = []  # ⚠️ 入队时立即标记，出队才标记会重复扩展
    while q:
        u = q.popleft(); out.append(u)
        for v in adj.get(u, ()):
            if v not in seen:
                seen.add(v); q.append(v)
    return out

adj = {"A": ["B","C"], "B": ["D"], "C": ["D"], "D": ["E"], "E": []}
print(bfs_order(adj, "A"))
# ⚠️ 稠密图用邻接表反而不便 O(1) 查边（换矩阵）；递归 DFS 深度过大爆栈，改显式栈
```

### Dijkstra 最短路 (Dijkstra)——非负权图单源最短路（导航、网络延迟、代价图）

**标准写法**：直接用 networkx，优先队列与判重已内置，O((V+E)log V)。

```python
import networkx as nx

G = nx.DiGraph()
G.add_weighted_edges_from([("s","a",4),("s","b",2),("b","a",1),("a","t",2),("b","t",5)])
dist, path = nx.single_source_dijkstra(G, "s", weight="weight")
print(dist)          # 各点最短距离
print(path["t"])     # 前驱路径
```

**陷阱规避写法**：负权边让 Dijkstra 的贪心前提失效，结果是**静默错误**（不是报错）——动手前先验边权。

```python
import networkx as nx

G = nx.DiGraph()
G.add_weighted_edges_from([("s","a",4),("s","b",1),("b","a",5),("a","t",1)])   # 全正权
G2 = nx.DiGraph()
G2.add_weighted_edges_from([("s","a",1),("s","b",3),("b","a",-3),("a","t",1)])  # 有负权

print(nx.single_source_bellman_ford(G, "s")[0])   # 无负权时两法一致
print(nx.single_source_bellman_ford(G2, "s")[0])  # Bellman–Ford 修正：s→a = 0（经 b 绕行更短）
try:
    print("Dijkstra:", nx.single_source_dijkstra(G2, "s")[0])  # ⚠️ 负权下给错值或报错
except ValueError as e:
    print("Dijkstra 拒绝负权:", e)
# ⚠️ 实现细节：应"入队时判重"而非"出队时判重"，否则复杂度爆炸（networkx 已处理）
```

### 最小生成树 (Minimum Spanning Tree: Kruskal / Prim)——最少代价连通全图（布线、管道、聚类）

Kruskal 与 Prim 的选择只影响常数与适用稀疏/稠密性，结果都是总权最小的 V−1 条边。

```python
import networkx as nx

G = nx.Graph()
G.add_weighted_edges_from([("a","b",1),("b","c",2),("a","c",3),("c","d",4),("b","d",5)])
T = nx.minimum_spanning_tree(G)
print(sorted(T.edges()))       # MST 边集
print(T.size(weight="weight")) # 总权（⚠️ 边权并列时 MST 不唯一，核对总权而非具体边）
print(nx.is_connected(G))      # ⚠️ 先判连通：不连通时得到的是最小森林（各分量一棵）
```

### 最大流与最小割 (Max-Flow / Min-Cut)——带容量约束的输送、"最少删几条边断开 s 与 t"

最大流 = 最小割容量。自己实现时残量网络必须含反向边；用整数容量（浮点容量有不停机风险），networkx 已内置这些保障。

```python
import networkx as nx

D = nx.DiGraph()
D.add_edge("s","a",capacity=10); D.add_edge("s","b",capacity=5)
D.add_edge("a","t",capacity=5);  D.add_edge("b","t",capacity=10)
D.add_edge("a","b",capacity=15)
print(nx.maximum_flow_value(D, "s", "t"))          # 最大流值
cut, (S, T) = nx.minimum_cut(D, "s", "t")
print(cut, S, T)   # ⚠️ 割容量 == 最大流；S 是与源同侧的顶点集
# ⚠️ 残量网络必须含反向边（自写时漏建直接错）；容量用整数不用浮点
```

### 二分图匹配 (Bipartite Matching & König)——任务分配、师生配对、"互不相邻"选取

先二染色确认图真是二分图（含奇环则不是）；König 定理（最大匹配 = 最小点覆盖）只在二分图成立，用 `to_vertex_cover` 从匹配构造点覆盖。

```python
import networkx as nx
from networkx.algorithms import bipartite

B = nx.Graph([("t1","w1"),("t1","w2"),("t2","w2"),("t3","w1"),("t3","w3")])
left = {"t1","t2","t3"}                       # 左部顶点集
print(bipartite.is_bipartite(B))              # ⚠️ 先确认是二分图（含奇环则不是）
match = bipartite.maximum_matching(B, top_nodes=left)
print(len(match) // 2, match)                 # 最大匹配数（dict 双向映射各记一次）
# König：最小点覆盖 == 最大匹配（to_vertex_cover 不传 top_nodes 时要求图连通，
# 否则 networkx 无法判定左右部抛 AmbiguousSolution；非连通图显式传 top_nodes 即可）
print(bipartite.to_vertex_cover(B, match))
```

### 排列与组合 (Permutations & Combinations)——"多少种方式"计数、概率分母、枚举规模估算

四象限（有序/无序 × 可重复/不可重复）选错公式是最常见错误；先算规模再枚举。

```python
import math
from itertools import permutations, combinations

print(math.perm(10, 3), math.comb(10, 3))   # 有序 720 / 无序 120
print(len(list(permutations("abcd", 2))), len(list(combinations("abcd", 2))))
# 四象限对照：有序可重复 n**k；无序可重复（多重集）comb(n+k-1, k)
print(10 ** 3, math.comb(10 + 3 - 1, 3))
print(math.factorial(20))   # Python int 任意精度直接算
# ⚠️ 21! 已溢出 int64——C++/Java 必须取模或用对数算；Python 没有溢出但会变慢
# ⚠️ 枚举前先估算 comb(n,k) 规模，别把 10^9 级方案真的一枚举
```

### 容斥原理 (Inclusion–Exclusion)——数"至少满足一个"、数"全都不满足"（转补集）

多集合按 2ᵏ 个子集交替加减，修正直接相加的重复计数。

```python
import math

# 1..100 中被 2 或 3 或 5 整除的个数
n = 100
cnt = lambda d: n // d
total = cnt(2) + cnt(3) + cnt(5) - cnt(6) - cnt(10) - cnt(15) + cnt(30)
print(total)      # 74
print(n - total)  # 全都不满足 = 补集计数 26
# ⚠️ 每个交集必须能精确算出，否则容斥落不了地
# ⚠️ 子集枚举 2^k 在 k>20 左右爆炸，需换统计技巧（如按位DP/莫比乌斯）
```

### 递推关系与主定理 (Recurrence & Master Theorem)——由递归结构直接读出复杂度

T(n)=aT(n/b)+f(n) 型分治的渐近阶对照表（此条目以表代码，主定理本身是查表工具）：

| 递推式 | 典型算法 | 结论 |
|---|---|---|
| T(n)=T(n/2)+O(1) | 二分查找 | Θ(log n) |
| T(n)=2T(n/2)+O(n) | 归并排序 | Θ(n log n) |
| T(n)=2T(n/2)+O(1) | 满二叉树遍历 | Θ(n) |
| T(n)=7T(n/2)+O(n²) | Strassen 型（矩阵乘法） | Θ(n^log₂7) |
| T(n)=T(n−1)+O(n) | 逐层削减 | Θ(n²) |

```python
import math
# 数值验证主定理：T(n)=2T(n/2)+n 按 Θ(n log n) 增长（比值趋常数）
def T(n):
    return 1 if n == 1 else 2 * T(n // 2) + n
for n in (2 ** k for k in (4, 8, 12)):
    print(n, T(n), f"{T(n) / (n * math.log2(n)):.3f}")
# ⚠️ 三种情形的边界（f(n) 与 n^{log_b a} 的多项式关系）易判错
# ⚠️ f(n) 落在情形缝隙（如 n/log n）时主定理不适用，回手归纳证
```

### 模运算 (Modular Arithmetic)——循环结构、哈希、密码学、大数防溢出

Python 的 `%` 结果符号随除数（n>0 时非负）；C/Java 符号随被除数——跨语言写哈希/循环索引时必须显式规范化。

```python
print(-7 % 3)    # Python → 2（非负）；C/Java 里 -7 % 3 == -1（符号随被除数）
# ⚠️ 跨语言差异：写哈希取桶、循环环形索引时，先规范化到 [0, n)
def mod(a, n):
    return a % n           # Python 的 % 在 n>0 时已保证落在 [0, n)
print(mod(-7, 3), (10**18 + 7) % (10**9 + 7))
# ⚠️ 模世界没有除法，只有乘逆元：a/b ≡ a * b^{-1}（b 的逆元见"费马小定理"卡段；
#    模数非素数时逆元要用扩展欧几里得，不存在会报错）
```

### 置换与轮换分解 (Permutation & Cycle Decomposition)——洗牌分析、对称性枚举、置换密码

任何置换唯一分解为不相交轮换；置换的阶 = 各轮换长的最小公倍数。

```python
import math

perm = {1: 3, 2: 1, 3: 2, 4: 5, 5: 4}   # 映射表示：i -> perm[i]

def cycles(p):
    seen, out = set(), []
    for s in p:
        if s in seen:
            continue
        c, x = [], s
        while x not in seen:
            seen.add(x); c.append(x); x = p[x]
        out.append(c)
    return out

cs = cycles(perm)
print(cs)                        # 轮换分解 [[1,3,2],[4,5]]
print(math.lcm(*map(len, cs)))   # 置换的阶 = lcm(3,2) = 6
# ⚠️ 置换乘法的左右作用顺序约定因教材而异，必须显式声明
# ⚠️ 奇偶性决定该置换能否由偶数次对换实现（奇置换不可能走到恒等）
```

### 整除与素数 (Divisibility & Primality)——判素、分解小整数、构造互素关系

试除 O(√n) 只适合 64 位内的小数；大数判素用 Miller–Rabin 而非硬分解。1 不是素数。

```python
import math

def is_prime(n):
    if n < 2: return False                # ⚠️ 1 不是素数，别漏这个分支
    if n % 2 == 0: return n == 2
    for p in range(3, math.isqrt(n) + 1, 2):
        if n % p == 0: return False
    return True

print(is_prime(97), is_prime(1), is_prime(9_999_999_937))

def factorize(n):                          # 试除分解（小整数够用）
    fs, d = {}, 2
    while d * d <= n:
        while n % d == 0:
            fs[d] = fs.get(d, 0) + 1; n //= d
        d += 1 if d == 2 else 2
    if n > 1: fs[n] = fs.get(n, 0) + 1
    return fs

print(factorize(360))   # {2: 3, 3: 2, 5: 1}
# ⚠️ 试除 O(√n) 对大数不可行——大数判素换 Miller–Rabin，别硬分解
```

### 欧几里得算法与扩展 (Euclidean / Extended GCD)——约分、模逆元、判断互素

扩展版同时解出 ax+by=gcd(a,b)（贝祖等式），是求模逆元与中国剩余的钥匙。日常直接用 `math.gcd`。

```python
import math

print(math.gcd(12, 18), math.lcm(4, 6))   # 日常用标准库

def ext_gcd(a, b):
    """返回 (g, x, y) 使 a*x + b*y = g"""
    if b == 0:
        return a, 1, 0
    g, x, y = ext_gcd(b, a % b)
    return g, y, x - (a // b) * y

g, x, y = ext_gcd(240, 46)
print(g, 240 * x + 46 * y)                # 贝祖等式验证：g=2，2 = 240x + 46y
# ⚠️ gcd 对 0/负数的约定各库不一（math.gcd(0,0)==0）；跨语言代码先核对边界约定

def inv_mod(a, n):                        # a 在 mod n 下的逆元
    g, x, _ = ext_gcd(a % n, n)
    if g != 1:
        raise ValueError("不互素，逆元不存在")   # ⚠️ 前提是 gcd(a, n) == 1
    return x % n

print(inv_mod(3, 7))    # 5（3*5 = 15 ≡ 1 (mod 7)）
```

### 素数筛 (Sieve of Eratosthenes)——批量小素数（多查询、预处理分解），不是判单个大数

埃氏筛 O(n log log n) 一次标出 [1,n] 全部素数；内存 O(n)，n 到 10⁹ 量级会爆。

```python
def sieve(n):
    """埃氏筛：返回 [1, n] 内全部素数"""
    is_p = bytearray([1]) * (n + 1)       # bytearray 比布尔列表省 ~8 倍内存
    is_p[0:2] = b"\x00\x00"
    for p in range(2, int(len(is_p) ** 0.5) + 1):
        if is_p[p]:
            is_p[p*p::p] = bytearray((n - p*p) // p + 1)   # 从 p² 起筛（更小倍数已被筛）
    return [i for i in range(n + 1) if is_p[i]]

print(sieve(30))
print(len(sieve(1_000_000)))   # 78498
# ⚠️ 内存 O(n)，n 到 1e9 量级爆内存；判单个大数用 Miller–Rabin 而非筛
```

### 模幂运算 (Modular Exponentiation)——大指数取模、费马/Miller–Rabin 检验、Diffie–Hellman

快速平方 O(log e)。**能用内置三参 `pow(a, e, n)` 就别手写**；手写必须边乘边取模。

```python
print(pow(7, 644, 645))            # 内置三参 pow：O(log e)，生产代码一律用它
print(pow(2, 10**18, 10**9 + 7))   # 巨大指数毫秒级完成

def mpow(a, e, n):                 # 手写版仅用于理解原理 / 需要额外逻辑时
    r, a = 1, a % n
    while e:
        if e & 1:
            r = r * a % n          # ⚠️ 边乘边取模——先乘后模在其他语言会溢出
        a = a * a % n
        e >>= 1
    return r

print(mpow(7, 644, 645) == pow(7, 644, 645))
```

### 中国剩余定理 (Chinese Remainder Theorem)——合并多模约束、拆大数为小模数并行计算

模数两两互素时，同余方程组在 mod N（N=∏nᵢ）下有唯一解。用 sympy 一行；需要自实现时逐步合并两两方程。

```python
from sympy.ntheory.modular import crt
import math

x, M = crt([3, 5, 7], [2, 3, 2])   # x≡2 (mod 3), x≡3 (mod 5), x≡2 (mod 7)
print(int(x), int(M))              # 23, 105

def ext_gcd(a, b):                 # 自实现需扩展欧几里得（每块自含）
    if b == 0: return a, 1, 0
    g, x, y = ext_gcd(b, a % b)
    return g, y, x - (a // b) * y

def merge(r1, m1, r2, m2):         # 合并 x≡r1(mod m1) 与 x≡r2(mod m2)
    g, p, _ = ext_gcd(m1, m2)      # m1*p + m2*q = g
    if (r2 - r1) % g:
        raise ValueError("模数不互素且不同余，无解")   # ⚠️ 先验相容性
    M = m1 // g * m2
    t = (r2 - r1) // g * p % (m2 // g)
    return (r1 + m1 * t) % M, M

print(merge(2, 3, *merge(3, 5, 2, 7)))   # (23, 105)
# ⚠️ 答案要落到 [0, N) 区间；sympy 无解时返回 (None, None)，先判空再 int()
```

### 费马小定理与欧拉函数 (Fermat's Little Theorem & Euler Totient)——模素数逆元、大指数降幂、理解 RSA

p 素数则 a^(p−1)≡1 (mod p)，故模素数逆元 = a^(p−2) mod p；欧拉函数 φ(n) 把该结论推广到合数模（要求 gcd(a,n)=1）。

```python
p = 1_000_000_007
print(pow(3, p - 1, p) == 1)   # 费马小定理：a^(p-1) ≡ 1 (mod p)
print(pow(3, p - 2, p))        # 模素数逆元：a^(p-2)（配合三参 pow）

def phi(n):                    # 欧拉函数：1..n 中与 n 互素的个数
    result, d = n, 2
    while d * d <= n:
        if n % d == 0:
            while n % d == 0:
                n //= d
            result -= result // d
        d += 1 if d == 2 else 2
    if n > 1:
        result -= result // n
    return result

print(phi(12), pow(5, phi(12), 12) == 1)   # 4；欧拉定理 a^φ(n) ≡ 1（gcd(a,n)=1）
print(pow(2, 560, 561) == 1)   # ⚠️ 561 是 Carmichael 数：非素数却通过费马检验
# ⚠️ 费马检验的逆命题不真，可靠判素用 Miller–Rabin（多底 + 三参 pow）
```

## 反模式（代码级翻车）

- ❌ BFS 出队时才标记 visited（同一节点重复入队，队列爆炸）→ ✅ 入队时立即 `seen.add(v)`（见遍历骨架）
- ❌ 图里有负权边还跑 Dijkstra（静默给出错误距离）→ ✅ 动手前 `any(w < 0)` 扫一遍边权，有负换 Bellman–Ford
- ❌ 拿埃氏筛判单个 10⁹ 级大数（O(n) 内存直接爆）→ ✅ 单数判素用 Miller–Rabin（三参 pow 驱动），筛只服务批量小素数
- ❌ 手写模幂先 `r *= a` 再统一取模（C/Java 下溢出）→ ✅ 每步 `r = r * a % n`；或直接内置 `pow(a, e, n)`
- ❌ CRT 不验前提直接套公式（模数不互素时得出错解）→ ✅ 先查两两互素，不互素则验 `(r2−r1) % g == 0` 相容性
- ❌ 按直觉把 `-x % n` 写成负数（C/Java 语义带进 Python，或反之）→ ✅ 统一 `a % n`（n>0）落到 [0, n)，跨语言代码显式注释差异
