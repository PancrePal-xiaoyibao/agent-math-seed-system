## 模板代码

### AR/MA/ARMA/ARIMA (Autoregressive / Moving Average / ARIMA)——单变量序列短期预测的基准模型

AR 用自身滞后、MA 用滞后噪声线性组合建模平稳序列；ARIMA 先差分 d 次再建模，处理趋势非平稳。**定阶交给 AIC/BIC 扫描，别拍脑袋**；拟合完必须过 Ljung-Box 残差检验。

```python
import warnings
import numpy as np
from statsmodels.tsa.arima.model import ARIMA
from statsmodels.stats.diagnostic import acorr_ljungbox
rng = np.random.default_rng(0)
x = np.empty(300); x[0] = 0.0
for t in range(1, 300):
    x[t] = 0.6 * x[t - 1] + rng.normal()           # 真实 AR(1)，φ=0.6
# ⚠️ d 只在趋势非平稳时取 1：差分过度（d 过大）反而引入负单位根问题
orders = [(p, d, q) for p in range(3) for d in range(2) for q in range(3)]
def fit_aic(o):
    with warnings.catch_warnings():
        warnings.simplefilter("ignore")   # 垃圾阶(d=1/边界 p,q)的拟合警告属正常
        return ARIMA(x, order=o).fit().aic
best = min(orders, key=fit_aic)
print("AIC 最优阶 =", best)
fit = ARIMA(x, order=(1, 0, 0)).fit()
print(f"φ̂ = {fit.params[1]:.2f}（真值 0.6）")
lb_p = acorr_ljungbox(fit.resid, lags=[10], return_df=True)["lb_pvalue"].iloc[0]
print(f"Ljung-Box p = {lb_p:.3f}（>0.05 ⇒ 残差≈白噪声，信息提干净了）")
print(f"3 步预测: {fit.forecast(3).round(3)}")
```

### 平稳性与自相关诊断：ADF 检验、ACF/PACF (Stationarity: ADF Test, ACF & PACF)——建模前的体检

ADF 查单位根（非平稳），ACF/PACF 定 AR/MA 阶数并暴露季节性。**价格类序列先差分/取对数收益率再建模**，对非平稳价格直接回归是伪回归。

```python
import numpy as np
from statsmodels.tsa.stattools import adfuller, acf, pacf
rng = np.random.default_rng(0)
price = np.cumsum(rng.normal(size=300)) + 100     # 随机游走价格（非平稳）
ret = np.diff(np.log(price))                      # 对数收益率（平稳）
for name, s in [("价格  ", price), ("收益率", ret)]:
    stat, p = adfuller(s, result_object=True)[:2]
    print(f"ADF {name}: stat={stat:7.2f}, p={p:.4f}（p<0.05 拒绝单位根 ⇒ 平稳）")
a, pf = acf(ret, nlags=10), pacf(ret, nlags=10, method="ywm")
print("ACF[1..5]  =", a[1:6].round(3))
print("PACF[1..5] =", pf[1:6].round(3))
# 读阶：AR(p) → PACF p 阶截尾、ACF 拖尾；MA(q) → ACF q 阶截尾、PACF 拖尾
# ⚠️ ADF 小样本功效低："没检出非平稳"≠平稳；plot_acf/plot_pacf 需 matplotlib
```

### GARCH 族 (GARCH)——波动率聚集建模：大波动跟大波动

条件方差建模为自身滞后与平方残差滞后的函数，输出 σ̂²_{t+1} 预测。**先定均值方程、再对残差拟合 GARCH**；先检验 ARCH 效应存在才值得上，GARCH(1,1) 是默认起点。

```python
import numpy as np
from statsmodels.stats.diagnostic import het_arch
rng = np.random.default_rng(0)
r = np.empty(500)
sig2 = 0.04
for t in range(500):                    # 模拟 GARCH(1,1)：σ²=.05+.08·r²+.90·σ²
    r[t] = np.sqrt(sig2) * rng.normal()
    sig2 = 0.05 + 0.08 * r[t]**2 + 0.90 * sig2
lm_stat, lm_p, f_stat, f_p = het_arch(r, nlags=10)   # 对原始收益序列检验
# （statsmodels 0.14~0.15 会打一条 acorr_lm 的 0.16 迁移 FutureWarning，库内部行为，可忽略）
print(f"ARCH-LM p = {lm_p:.2e}（<0.05 ⇒ 存在 ARCH 效应，值得拟合 GARCH）")
# ⚠️ 均值方程先行：常数均值或 ARMA 拟合后，用其残差进入 GARCH；高阶(p,q)易过拟合
# 拟合与预测见文末「需安装」节的 arch 库示例
```

### 状态空间模型与卡尔曼滤波 (State-Space & Kalman Filter)——隐状态边来数据边估计

"隐状态演化 + 带噪观测"两组方程，线性高斯下递推最优。适用：动态 beta、动态对冲比率的在线估计。**Q/R 设定不当滤波会发散**。

```python
import numpy as np
rng = np.random.default_rng(0)
n = 100
beta_true = np.linspace(1.0, 1.5, n)              # 缓慢漂移的隐状态（动态对冲比率）
y_obs = 2.0 * beta_true + rng.normal(scale=0.3, size=n)   # 观测 y = x·β + v（x≡2）
# 一维卡尔曼模板：状态 β_t = β_{t-1} + w~N(0,Q)；观测 y_t = x_t·β_t + v~N(0,R)
Q, R = 1e-4, 0.3**2    # ⚠️ Q 大→追噪声抖动；R 大→钝化滞后。从噪声量级反推，逐步调
beta_hat, P, track = 1.0, 1.0, [1.0]
for k in range(1, n):
    beta_pred, P_pred = beta_hat, P + Q              # 1) 预测（随机游走转移）
    K = P_pred / (P_pred + R)                        # 2) 卡尔曼增益
    beta_hat = beta_pred + K * (y_obs[k] - 2.0 * beta_pred)   # 3) 更新（H=x_t=2）
    P = (1 - K) * P_pred
    track.append(beta_hat)
track = np.array(track)
print(f"滤波 RMSE={np.sqrt(((track - beta_true)**2).mean()):.3f}"
      f" vs 未滤波 {np.sqrt(((y_obs / 2 - beta_true)**2).mean()):.3f}")
print("线性高斯是前提；非线性换 EKF/UKF/粒子滤波")
```

### Granger 因果 (Granger Causality)——谁领先谁：预测层面的因果

加入 X 的滞后能显著改善对 Y 的预测 ⇒ "X Granger 引致 Y"。**只对平稳序列有意义**；是预测因果，不是结构因果。

```python
import numpy as np
from statsmodels.tsa.stattools import adfuller, grangercausalitytests
rng = np.random.default_rng(0)
x = np.empty(300); y = np.empty(300); x[0] = y[0] = 0.0
for t in range(1, 300):
    x[t] = 0.5 * x[t - 1] + rng.normal()
    y[t] = 0.4 * y[t - 1] + 0.5 * x[t - 1] + rng.normal()   # x 的滞后进入 y
for name, s in [("x", x), ("y", y)]:                     # ⚠️ 先确认两条都平稳
    print(f"ADF({name}) p = {adfuller(s, result_object=True)[1]:.3f}")
data = np.column_stack([y, x])    # 第 0 列=被解释变量 y，第 1 列=候选原因 x
res = grangercausalitytests(data, maxlag=2)
for lag, tests in res.items():
    print(f"x → y  lag={lag}: F 检验 p = {tests[0]['ssr_ftest'][1]:.4f}")
# ⚠️ Granger 因果 ≠ 真因果：遗漏变量/同期相关可造假象，别直接当结构性结论
```

## 反模式（代码级翻车）

- ❌ 对价格（非平稳）直接 ARIMA(p,0,q) 或回归 → ✅ 先 `adfuller`，不过关差分（d=1）或取对数收益率再建模；对非平稳价格直接回归 = 伪回归
- ❌ (p,d,q) 拍脑袋定，拟合完直接用 → ✅ AIC/BIC 扫阶 + ACF/PACF 读阶互相印证；残差必须过 `acorr_ljungbox`（p>0.05 才算白噪声）
- ❌ d 一路加到 2、3 追求"更平稳" → ✅ 差分过度引入负单位根；d 取能过 ADF 的最小值
- ❌ 收益率有波动聚集还直接上高阶 GARCH(3,3) → ✅ 先 `het_arch` 确认 ARCH 效应存在，GARCH(1,1) 起步，AIC 不支持再加阶
- ❌ 卡尔曼 Q/R 拍脑袋（或对称地设成同一个数）→ ✅ R 从测量噪声方差量级反推，Q 从状态漂移速度反推；滤波发散/滞后先查这两个参数
- ❌ 对两条非平稳序列跑 Granger 因果，p<0.05 就宣称"X 导致 Y" → ✅ 先 ADF 确认平稳；结论只到"领先滞后"层面，不能当结构性/政策依据
