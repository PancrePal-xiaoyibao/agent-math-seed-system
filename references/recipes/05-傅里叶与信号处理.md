## 模板代码

### 傅里叶级数 (Fourier Series)——周期信号的三角分解

基频由区间长度决定；间断点处级数收敛到左右极限的平均值。方波只含奇次谐波，系数 4/(πn)。**间断点附近的部分和永远带着 ~9% 的过冲（Gibbs 振荡）**——这是逼近性质，不是程序 bug。

```python
import numpy as np
N = 25                                          # 取前 N 项的部分和
x = np.linspace(0, 2 * np.pi, 4000, endpoint=False)
n = np.arange(1, N + 1, 2)                      # 方波只含奇次谐波
S = sum(4 / (np.pi * k) * np.sin(k * x) for k in n)
print(f"N={N} 部分和峰值 = {S.max():.4f}")        # 1.1795
print("Gibbs 常数 ≈ 1.1790：跳变 2 的 8.95% 超调，N 增大只向间断点挤压、高度不变")
# ⚠️ 看到"不该有的振荡"先想 Gibbs：加大 N 消不掉，平滑化（滤波/平均）才能压低
```

### 傅里叶变换 (Fourier Transform)——先对齐归一化约定再谈数值

时域卷积 = 频域乘积、求导 = 乘 iω，是频谱分析与解线性平移不变系统的原型。文献的正负指数与 1/2π 因子约定不统一，跨教材/跨库对比可能整体差 2π（或 N、√N）倍——**先用 Parseval 定理自检归一化**。

```python
import numpy as np
x = np.array([1.0, 2.0, 3.0, 4.0])
Xb = np.fft.fft(x)                       # norm='backward'（默认）：正变换不除 N
Xo = np.fft.fft(x, norm='ortho')         # 除 sqrt(N)
Xf = np.fft.fft(x, norm='forward')       # 除 N
print(Xb[1], Xo[1], Xf[1])               # (-2+2j) (-1+1j) (-0.5+0.5j)：同一谱线差 N / sqrt(N) 倍
print("Parseval 自检: 时域", (x**2).sum(),
      "| backward 频域", (np.abs(Xb)**2).sum(),   # = N × 时域能量
      "| ortho 频域", (np.abs(Xo)**2).sum())      # = 时域能量 ✓
# ⚠️ 跨库/跨文献比较幅度前：先确认 norm 约定与 1/2π 因子放哪边，用 Parseval 验证能量守恒
```

### 离散傅里叶变换与快速算法 (DFT & FFT)——频谱分析标准模板

DFT 把 N 个采样映射为 N 个频率系数，FFT 是 O(N log N) 快速实现。实信号用 `rfft` 只算正频率一半；频率轴用 `rfftfreq` 生成，k=0 是直流、最后一个 bin 是奈奎斯特频率。

标准写法（已知双音信号，峰值幅度一步恢复）：

```python
import numpy as np
from scipy.signal import find_peaks
fs = 100.0
t = np.arange(400) / fs                          # 窗长 4 s，Δf = 1/T = 0.25 Hz
sig = np.sin(2*np.pi*20*t) + 0.5*np.sin(2*np.pi*30*t + 0.7)   # 已知双音
X = np.fft.rfft(sig)                             # 实信号用 rfft：只算正频率一半
f = np.fft.rfftfreq(len(sig), 1/fs)              # 频率轴 = k·fs/N
amp = np.abs(X) * 2 / len(sig)                   # 幅度恢复：×2/N（直流与奈奎斯特项除外）
pk, _ = find_peaks(amp, height=0.3 * amp.max())
print("峰频率:", f[pk], "幅度:", amp[pk].round(2))   # [20. 30.] [1.  0.5]
```

陷阱规避写法（补零 ≠ 提分辨率——频率分辨率由窗长决定，补零只是频域插值）：

```python
import numpy as np
from scipy.signal import find_peaks
fs = 100.0
def two_tone(T):
    t = np.arange(int(T * fs)) / fs
    return np.sin(2*np.pi*10.0*t) + np.sin(2*np.pi*10.5*t)   # 两频相距 0.5 Hz
A = np.abs(np.fft.rfft(two_tone(0.5), n=512))    # 窗长 0.5s(Δf=2Hz)，补零到 512 点
f = np.fft.rfftfreq(512, 1/fs)
pk, _ = find_peaks(A, height=0.3*A.max(), distance=2)
print("0.5s 补零512:", f[pk], len(pk), "个峰——补零只是插值，一个鼓包还是一个鼓包")
A4 = np.abs(np.fft.rfft(two_tone(4.0), n=512))   # 真加窗长：Δf = 1/T = 0.25 Hz
pk4, _ = find_peaks(A4, height=0.3*A4.max(), distance=2)
print("4.0s 不补零:  ", f[pk4], len(pk4), "个峰——分辨率由窗长决定")
# ⚠️ 分辨率 = 1/窗长：要分开近频只能加长采样时间，补零不能替代
```

### 卷积 (Convolution)——LTI 系统输出 = 输入 ⊗ 脉冲响应

"滑动加权叠加"运算：系统输出、图像滤波模糊、概率密度之和都用它。频域乘法是长序列的 O(N log N) 加速路线，但 **FFT 隐含周期延拓——必须补零到 N+M−1**，否则循环折叠污染首尾。

```python
import numpy as np
from scipy.signal import fftconvolve
x, h = np.array([1., 2, 3, 4]), np.array([1., 1, 1])
lin = np.convolve(x, h)                          # 线性卷积，长度 N+M-1 = 6
bad = np.fft.ifft(np.fft.fft(x, 4) * np.fft.fft(h, 4)).real    # ❌ 补到 max(N,M)=4：循环卷积
good = np.fft.irfft(np.fft.rfft(x, n=6) * np.fft.rfft(h, n=6)) # ✅ 补零到 N+M-1
print("线性      ", lin)                         # [1. 3. 6. 9. 7. 4.]
print("循环(错)  ", bad.round(1))                # [8. 7. 6. 9.] 首尾折叠污染
print("补零到6   ", good.round(1), "| fftconvolve:", fftconvolve(x, h))  # 与线性一致
# ⚠️ 频域做线性卷积：rfft 双方补到 n=N+M-1 再 irfft；fftconvolve 内部已处理，长序列首选
```

### 相关：自相关与互相关 (Autocorrelation & Cross-correlation)——周期检测与延迟对齐

自相关找周期/回声，互相关找两信号的相对延迟（匹配滤波、雷达对齐）；自相关的傅里叶变换是功率谱（Wiener–Khinchin）。**比较相似性必须用归一化相关**，否则被幅度大小支配。

```python
import numpy as np
from scipy.signal import correlate, find_peaks
rng = np.random.default_rng(0)
fs = 100.0
t = np.arange(1000) / fs
sig = np.sin(2*np.pi*10*t) + 0.5*rng.standard_normal(len(t))
ac = correlate(sig, sig, mode='full')
lags = np.arange(-len(t)+1, len(t)) / fs
ac = ac / ac.max()                               # ✅ 归一化到 lag=0 处为 1
pk, _ = find_peaks(ac[lags > 0], height=0.2, distance=5)
print("自相关正 lag 前 5 峰:", lags[lags > 0][pk][:5], "（≈0.1 的整数倍 → 10 Hz 周期）")
delay = 0.07                                     # 互相关：找回声/对齐延迟
y = np.sin(2*np.pi*5*(t - delay)) + 0.3*rng.standard_normal(len(t))
cc = correlate(y, np.sin(2*np.pi*5*t), mode='full')
print(f"互相关峰 lag = {lags[np.argmax(cc)]:.3f} s（真实 0.070）")
# ⚠️ 互相关 ≠ 卷积（相差一次翻转）；自相关有峰 ≠ 周期严格成立，要看峰的显著性与衰减
```

### 采样定理 (Nyquist–Shannon)——fs > 2·f_max 才零信息损失

带限信号以 fs > 2·f_max 采样可完全重建。下面对带限双音做采样，频谱恰好只剩两根线，再由这两根线重构原信号——误差到机器精度，这就是"无损"的可运行证明。

```python
import numpy as np
fs, N = 100.0, 100                               # 窗长 1 s：20/30 Hz 均整周期、无泄漏
t = np.arange(N) / fs
f1, f2 = 20.0, 30.0                              # 最高频率 30 Hz < fs/2 = 50 ✓
x = 3*np.sin(2*np.pi*f1*t) + 1.5*np.sin(2*np.pi*f2*t + 0.7)
X = np.fft.rfft(x) / (N / 2)                     # 单边谱：幅度 = |X|·2/N
f = np.fft.rfftfreq(N, 1/fs)
k = np.where(np.abs(X) > 1e-9)[0]
print("非零谱线:", f[k], "幅度:", np.abs(X[k]).round(3))   # [20. 30.] [3.  1.5]
xr = sum(np.abs(X[i]) * np.cos(2*np.pi*f[i]*t + np.angle(X[i])) for i in k)
print("由谱线重构误差 = %.1e（fs > 2B 采样零信息损失）" % np.abs(xr - x).max())
# ⚠️ "带限"是前提：真实信号先抗混叠低通再采样；2 倍是理论下限，工程取 2.5-4 倍留过渡带
```

### 混叠 (Aliasing)——高频折叠伪装成低频，事后无解

采样不足时 f 高于 fs/2 的分量按 f_alias = |f − k·fs| 折叠进 ±fs/2 内伪装成低频；**时域完全看不出来，只在频域暴露**，且一旦发生无法事后修复。

```python
import numpy as np
fs = 100.0
t = np.arange(200) / fs                          # fs/2 = 50 Hz
sig = np.sin(2*np.pi*70.0*t)                     # 70 Hz 高于奈奎斯特：必混叠
X = np.abs(np.fft.rfft(sig))
f = np.fft.rfftfreq(len(sig), 1/fs)
print("70 Hz 信号的谱峰出现在", f[np.argmax(X)], "Hz")     # 30.0：伪装成低频
fold = lambda fr, fs: abs(fr - round(fr / fs) * fs)        # 折叠频率公式
print({fr: fold(fr, fs) for fr in (10, 60, 70, 90, 110)})
# {10: 10, 60: 40, 70: 30, 90: 10, 110: 10}
# ⚠️ 频谱里冒出"不可能的低频"先算折叠表核对；已混叠数据只能重采（先抗混叠滤波），不能补救
```

### 窗函数 (Window Function)——压泄漏，代价是主瓣展宽

非整周期截断 → 频谱泄漏（能量从谱线散到全频段）。加缓变窗（Hann/Hamming/Blackman）压旁瓣泄漏，代价是主瓣展宽。下面演示泄漏噪声底淹没弱信号的经典翻车，以及加窗后的幅值校正。

```python
import numpy as np
fs, N = 100.0, 400
t = np.arange(N) / fs
sig = np.sin(2*np.pi*10.3*t) + 0.001*np.sin(2*np.pi*40.0*t)   # 弱信号 -60 dB
def db(a, b): return 20 * np.log10(a / b)
for name, w in (("矩形(无窗)", np.ones(N)), ("Hann", np.hanning(N))):
    X = np.abs(np.fft.rfft(sig * w, n=4096))
    f = np.fft.rfftfreq(4096, 1/fs)
    band = (f > 37) & (f < 43)
    floor = db(X[band].max(), X.max())
    print(f"{name}: 37-43Hz 最高 {floor:.0f} dB → 弱信号@40Hz",
          "可见" if floor < -55 else "被泄漏淹没")
w = np.hanning(N)
X = np.abs(np.fft.rfft(sig * w, n=4096)) * 2 / w.sum()   # ✅ 相干增益校正
print("Hann 校正后 10.3 Hz 幅度 =", X.max().round(3), "（真 1.0）")
# ⚠️ 加窗后幅值必须按相干增益(窗均值)校正，否则系统性偏低；选窗是主瓣宽(分辨率)↔旁瓣低(泄漏)折衷
```

### 小波变换 (Wavelet Transform)——多分辨率时频（需安装）

> **需 `pip install PyWavelets`（pywt 未进预装清单，本块不进可运行验证）**。用可平移伸缩的母小波做分解，给出"何时发生什么频率"的多分辨率表示，弥补 STFT 固定分辨率的不足；适合突变/瞬态/调频等非平稳信号。

```python
# 需 pip install PyWavelets
import numpy as np
import pywt
t = np.arange(1000) / 100.0
sig = np.concatenate([np.cos(2*np.pi*5*t[:500]), np.cos(2*np.pi*20*t[500:])])
coef, freqs = pywt.cwt(sig, scales=np.arange(1, 32), wavelet='cmor1.5-1.0')
# CWT：系数面 (尺度×时间)，高度冗余——用于时频定位"分析"，勿拿它压缩/重构
coeffs = pywt.wavedec(sig, wavelet='db4', level=4)     # 正交 DWT：无冗余
rec = pywt.waverec(coeffs, wavelet='db4')
print("DWT 完美重构:", np.allclose(rec[:len(sig)], sig))   # True
# ⚠️ 连续 CWT 用来分析（冗余时频面）；压缩/去噪/重构必须用正交(双正交) DWT，可完美重构
```

## 反模式（代码级翻车）

- ❌ 跨库/跨教材直接比较 FFT 幅度 → ✅ 先对齐 norm 约定（`backward/ortho/forward`）与 1/2π 因子位置，用 Parseval 定理验能量守恒后再比
- ❌ 补零想提高频率分辨率（N 从 512 补到 8192 就能分开近频）→ ✅ 分辨率 = 1/窗长：加长采样时间；补零只做频域插值，鼓包还是鼓包
- ❌ 频域乘法做线性卷积不补零（`fft(x)*fft(h)` 直接 `ifft`）→ ✅ 双方补到 `n=N+M-1` 后 `irfft`（`rfft` 配 `irfft`，别配 `ifft`），或直接 `fftconvolve`；边界处理模式（zero/periodic/reflect、full/same）结果差异大，必须显式声明
- ❌ 用卷积函数算互相关、拿未归一化相关比相似度 → ✅ 用 `scipy.signal.correlate`（翻转方向不同）；除以 lag=0 值归一化后再比
- ❌ 频谱冒出低频伪峰当真实成分、混叠数据想办法"修" → ✅ 先算折叠频率 `|f − round(f/fs)·fs|` 核对；混叠只能重采（采样前加抗混叠低通），事后无法补救
- ❌ 加窗后直接读谱峰幅度 → ✅ 幅值除以窗的相干增益（如 `2/w.sum()`）校正；选窗认"主瓣宽 ↔ 旁瓣低"的折衷，没有全能窗
