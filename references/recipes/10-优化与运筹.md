## 模板代码

### 凸性判定 (Convexity Check)——设计优化管线前先问"这问题凸不凸"

凸则局部最优即全局最优，可以放心用闭式解/凸求解器；非凸才需要全局方法。数值自查走二阶条件（Hessian 特征值），但记住：**网格采样只能证伪凸性，证明要走保凸运算清单**（加法、非负加权和、仿射复合、逐点最大化）。

```python
import numpy as np
g = np.linspace(-2, 2, 9)
pts = [np.array([a, b]) for a in g for b in g]
hess_convex = lambda p: np.array([[2.0, 1.0], [1.0, 4.0]])          # f = x²+2y²+xy
hess_saddle = lambda p: np.array([[12 * p[0]**2 - 6, 0.], [0., 0.]])  # f = x⁴−3x²+x（y 方向平）
def min_eig_grid(hess, points):
    return min(np.linalg.eigvalsh(hess(p)).min() for p in points)
print(f"f1 网格最小特征值 = {min_eig_grid(hess_convex, pts):.2f}  → 处处≥0：凸，局部即全局")
print(f"f2 网格最小特征值 = {min_eig_grid(hess_saddle, pts):.2f}  → 变号：非凸，须全局方法")
# ⚠️ "看起来凸"≠凸：网格抓到负特征值即证伪凸性（下方 f2 就是实锤）；但有限采样点≥0 不能证明凸——证明要走保凸运算清单；max(仿射) 保凸，min 不保凸，方向别搞反
# ⚠️ 约束的凸性同样要查：可行域是凸集（仿射等式 + 不等式 g(x)≤0 且 g 凸）才谈得上凸问题
```

### 梯度下降家族 (SGD / Momentum / Adam)——大规模可微损失的默认引擎

SGD 沿负梯度走、Momentum 累积惯性、Adam 用一/二阶矩做逐参数自适应步长。手写 Adam 一次看懂全部三件套（矩、偏差修正、eps）：

```python
import numpy as np
def f(p): return (1 - p[0])**2 + 100 * (p[1] - p[0]**2)**2        # Rosenbrock 病态香蕉谷
def grad(p):
    return np.array([-2 * (1 - p[0]) - 400 * p[0] * (p[1] - p[0]**2),
                     200 * (p[1] - p[0]**2)])
x = np.array([-1.2, 1.0]); lr, b1, b2, eps = 2e-3, 0.9, 0.999, 1e-8
f0 = f(x)
m = v = np.zeros(2)
for t in range(1, 20001):
    g = grad(x)
    m = b1 * m + (1 - b1) * g                          # 一阶矩（带惯量的梯度均值）
    v = b2 * v + (1 - b2) * g**2                       # 二阶矩（逐参数曲率尺度）
    m_hat, v_hat = m / (1 - b1**t), v / (1 - b2**t)    # ✅ 偏差修正：缺了它前几百步步长被 0 初值稀释
    x -= lr * m_hat / (np.sqrt(v_hat) + eps)           # 逐参数步长，量纲自适应
print(f"Adam 20000 步: f {f0:.2f} → {f(x):.2e}   x* = {x.round(4)}（最优点 (1,1)）")
# ⚠️ lr 过大发散、过小假停滞；minibatch 噪声曲线先平滑再诊断；AdamW(解耦权重衰减)≠Adam+L2
```

### 牛顿法与拟牛顿 (Newton & BFGS / L-BFGS)——中小规模平滑问题的高精度收敛

BFGS 用历史梯度低秩近似逆 Hessian（免算二阶导），L-BFGS 省内存是大维度默认。**解析梯度必给**：数值差分慢且在不光滑处失真。

```python
import numpy as np
from scipy.optimize import minimize
def f(p): return (1 - p[0])**2 + 100 * (p[1] - p[0]**2)**2
def g(p): return np.array([-2 * (1 - p[0]) - 400 * p[0] * (p[1] - p[0]**2),
                           200 * (p[1] - p[0]**2)])
x0 = np.array([-1.2, 1.0])
r1 = minimize(f, x0, method='BFGS')                       # ❌ 无 jac：数值差分，评估次数多
r2 = minimize(f, x0, method='BFGS', jac=g)                # ✅ 解析梯度：更少评估、更稳
r3 = minimize(f, x0, method='L-BFGS-B', jac=g,
              bounds=[(-2, 2), (0, 3)])                   # 大维度 / 带边界约束首选
print(f"数值梯度: nfev={r1.nfev:3d}  f={r1.fun:.2e}")
print(f"解析梯度: nfev={r2.nfev:3d}  f={r2.fun:.2e}")
print(f"L-BFGS-B: x*={r3.x.round(3)}  f={r3.fun:.2e}")
# ⚠️ 非凸处 Hessian 不定会走错方向（需阻尼/信赖域）；目标含 |x|、ReLU 等不可导点直接翻车
```

### KKT 条件 (Karush–Kuhn–Tucker Conditions)——校验约束最优解的"验钞机"

拉格朗日驻点 + 原始可行 + 对偶可行（λ≥0）+ 互补松弛，凸问题下四条全过 = 全局最优。对求解器输出做 KKT 自查是最便宜的 correctness 检查：

```python
import numpy as np
from scipy.optimize import minimize
# min (x−3)²  s.t. x≥5：无约束最优 x=3 被约束顶住 → 最优在边界 x*=5
r = minimize(lambda z: (z[0] - 3)**2, [0.0], method='SLSQP',
             constraints=[{'type': 'ineq', 'fun': lambda z: z[0] - 5}])
lam = 2 * (r.x[0] - 3)                     # 驻点 ∇f+λ∇g=0 → λ=−f'(x*)=2(x*−3)
print(f"x* = {r.x[0]:.1f}   λ = {lam:.1f}")
# ✅ KKT 四查：驻点成立 / 原始可行 x*≥5 / 对偶可行 λ≥0 / 互补松弛 λ(x*−5)=0 —— 全过
# ⚠️ λ<0 或约束没顶住（x*>5 却 λ≠0）说明解错；非凸或缺 Slater 条件时 KKT 只是必要不充分
```

### 线性规划：单纯形法 (Linear Programming: Simplex)——线性目标+线性约束的资源分配

生产上直接调 HiGHS（`linprog` 默认），别手写单纯形。`ineqlin.marginals` 直接给出影子价格。**linprog 只做 min**，max 问题目标取负：

```python
import numpy as np
from scipy.optimize import linprog
# 两产品 x1,x2：max 3x1+5x2  s.t. x1≤4, 2x2≤12, 3x1+2x2≤18（工时/原料）
res = linprog(c=[-3, -5],                        # ✅ max 取负转 min，读结果再取负
              A_ub=[[1, 0], [0, 2], [3, 2]], b_ub=[4, 12, 18],
              method='highs')
print(f"最优利润 = {-res.fun:.1f}（x1={res.x[0]:.0f}, x2={res.x[1]:.0f}）")
print("影子价格 =", (-res.ineqlin.marginals).round(2), "← 每放宽一单位该资源，利润增量")
# ⚠️ 约束量纲差多个数量级会拖垮数值精度 → 先缩放归一再求解
```

### 线性规划对偶 (LP Duality)——给"哪个约束在卡脖子"定价

每个 LP 都有对偶：弱对偶给界、强对偶给等值，对偶变量即资源影子价格。显式构造一遍对偶，验证强对偶成立：

```python
import numpy as np
from scipy.optimize import linprog
# 原始 min 3x1+5x2  s.t. x1+2x2≥12, 3x1+x2≥18  ↔  对偶 max 12y1+18y2  s.t. Aᵀy≤c, y≥0
A, c, b = np.array([[1., 2.], [3., 1.]]), [3., 5.], [12., 18.]
p = linprog(c, A_ub=-A, b_ub=-np.array(b), method='highs')      # ≥ 约束取负转 ≤
d = linprog([-v for v in b], A_ub=A.T, b_ub=c, method='highs')  # ✅ 对偶 = 转置换目标
print(f"原始目标 = {p.fun:.2f}   对偶目标 = {-d.fun:.2f}   （强对偶：相等）")
print(f"对偶解 y* = {d.x.round(2)}  ← 每种资源的影子价格（只在不等号取等的紧约束处非零）")
# ⚠️ 原始无界 ↔ 对偶不可行：解读前先检查双方 status，别拿不可行的对偶讲故事
```

### 凸优化与二次规划 (Convex Optimization & QP)——识别为凸，就把问题交给成熟求解器

QP（凸二次目标+线性约束）是最常用特例：马科维茨组合、SVM、模型预测控制。凸性有保证时局部最优即全局最优。先看 scipy 能不能解，量大/约束多再上 cvxpy（见「需安装」）：

```python
import numpy as np
from scipy.optimize import minimize
# 两资产马科维茨：min wᵀΣw  s.t. w1+w2=1, 预期收益≥8%（QP：目标凸+约束仿射）
S = np.array([[0.04, 0.01], [0.01, 0.09]])               # 协方差阵
mu = np.array([0.05, 0.10])
print("Σ 特征值 =", np.linalg.eigvalsh(S).round(3), "→ 全正，Hessian 常正定，严格凸")
r = minimize(lambda w: w @ S @ w, [0.5, 0.5], method='SLSQP',
             constraints=[{'type': 'eq', 'fun': lambda w: w.sum() - 1},
                          {'type': 'ineq', 'fun': lambda w: w @ mu - 0.08}])
print(f"w* = {r.x.round(3)}   组合方差 = {r.fun:.4f}（σ = {np.sqrt(r.fun):.3f}）")
# ⚠️ 含 rank/整数约束的"伪凸 QP"会被静默解成局部解——先确认约束全是仿射的
```

### 模拟退火 (Simulated Annealing)——组合/非凸问题的全局兜底

高温按 `min(1, exp(−Δ/T))` 允许劣化跳坑，几何降温逐步冻结。目标函数/邻域结构/温度调度三件套，以 6 城 TSP 骨架演示：

```python
import numpy as np
rng = np.random.default_rng(0)
xy = rng.uniform(0, 10, size=(6, 2))
D = np.linalg.norm(xy[:, None] - xy[None, :], axis=-1)
def tour_len(s): return D[s, np.roll(s, -1)].sum()
s = rng.permutation(6); T, best = 5.0, tour_len(s)       # 初温要够高（劣化能被接受）
for _ in range(8000):
    i, j = sorted(rng.choice(6, 2, replace=False))
    s2 = np.concatenate([s[:i], s[i:j + 1][::-1], s[j + 1:]])   # 邻域：2-opt 反转一段
    d = tour_len(s2) - tour_len(s)
    if d < 0 or rng.random() < np.exp(-d / T):           # ✅ Metropolis 准则：劣化概率接受
        s = s2
        best = min(best, tour_len(s))
    T = max(T * 0.999, 0.05)                             # 几何降温：太快→贪心爬山，太慢→浪费时间
print(f"SA 最短回路 ≈ {best:.3f}（6 城规模可暴力枚举对拍确认是否全局最优）")
# ⚠️ SA 无收敛证书：本例恰中全局最优是运气不是保证——多次独立重启取最优才是标准姿势
```

### 排队论 M/M/1 (M/M/1 Queue)——容量规划的闭式速算

泊松到达+指数服务的单队列，公式直接算，不用仿真。核心一句话：**ρ→1 时等待时间爆炸**。

```python
lam, mu = 8.0, 10.0                     # 到达率 λ、服务率 μ（单位：人/小时）
rho = lam / mu
if rho >= 1:
    raise SystemExit("ρ≥1：队列爆炸，无稳态——先扩容再来")
L = rho / (1 - rho)                     # 稳态平均队长 L = ρ/(1−ρ)（含在服务中的）
W = 1 / (mu - lam)                      # 平均逗留时间 W = 1/(μ−λ)
Wq = rho / (mu - lam)                   # 平均排队等待（不含服务）= W − 1/μ
print(f"ρ={rho}  L={L:.2f} 人  W={W*60:.1f} 分钟  Wq={Wq*60:.1f} 分钟")
print(f"P(队长≥5) = {rho**5:.3f}   ← M/M/1 尾概率 = ρ^k")
# ⚠️ ρ 接近 1 时 W 对 λ 极敏感：现实系统按 70–80% 利用率设计，别把 ρ 规划到 0.95
# ⚠️ 真实到达非泊松（有批量/高峰）时闭式失真，改 M/G/1 或直接仿真
```

### 马尔可夫决策过程 (Markov Decision Process)——"今天的决策影响明天的状态"

五元组 (S,A,P,r,γ) 的序贯决策，值迭代解贝尔曼最优方程（γ<1 压缩映射必收敛）。3×4 网格世界 20 行看懂全流程：

```python
import numpy as np
# 每步 -0.04，右上格 +1 / 右中格 -1 为终点；γ=0.9；0.8 主方向 + 0.1×2 侧滑
terminal = {(0, 3), (1, 3)}
moves = [(-1, 0), (1, 0), (0, -1), (0, 1)]
reward = lambda s: 1.0 if s == (0, 3) else -1.0 if s == (1, 3) else -0.04
V = np.zeros((3, 4))
for _ in range(150):                                     # 贝尔曼最优算子反复应用（γ<1 收缩）
    Vn = V.copy()
    for i in range(3):
        for j in range(4):
            if (i, j) in terminal:
                continue
            best_q = -np.inf
            for di, dj in moves:
                q = 0.0
                for p, (si, sj) in [(0.8, (di, dj)), (0.1, (dj, -di)), (0.1, (-dj, di))]:
                    ni, nj = i + si, j + sj
                    ni, nj = (i + si, j + sj) if (0 <= i + si < 3 and 0 <= j + sj < 4) else (i, j)  # 撞墙留原地
                    q += p * (reward((ni, nj)) + (0.9 * V[ni, nj] if (ni, nj) not in terminal else 0.0))
                best_q = max(best_q, q)
            Vn[i, j] = best_q
    V = Vn
print(np.round(V, 2))                                    # 越靠近 +1 的格子值越高
# ⚠️ 状态空间指数膨胀（维度灾难）；转移矩阵未知时从数据学（RL 路线），别假设模型已知
```

### 动态规划与贝尔曼方程 (Dynamic Programming & Bellman Equation)——有最优子结构的阶段决策

把多阶段决策拆成重叠子问题，`V(s)=max_a[r+γ·E·V(s′)]` 递推。0/1 背包是 DP 的最小完整模板（滚动数组空间 O(cap)）：

```python
def knapsack(weights, values, cap):
    """0/1 背包：dp[c] = 容量 c 下最大价值；逆序滚动数组一维化"""
    dp = [0] * (cap + 1)
    for w, v in zip(weights, values):
        for c in range(cap, w - 1, -1):        # ✅ 逆序：每件最多选一次（正序=完全背包）
            dp[c] = max(dp[c], dp[c - w] + v)
    return dp[cap]
best = knapsack(weights=[2, 3, 4, 5], values=[3, 4, 5, 8], cap=8)
print(f"最优价值 = {best}")                     # 选 {3,5}：容量 8 用满，价值 4+8=12
# ⚠️ 状态设计漏变量会破坏无后效性；连续状态需离散化/函数近似，精度与维数的取舍是核心难点
```

### cvxpy——QP/SOCP 的工业级建模语言（Disciplined Convex Programming）

> **需 pip install cvxpy**。约束多、要换求解器（OSQP/ECOS/Clarabel）、要对偶信息时用 cvxpy 写 DCP 形式，比手搓 SLSQP 清晰得多。

```python
# 需 pip install cvxpy
import cvxpy as cp
import numpy as np
S = np.array([[0.04, 0.01], [0.01, 0.09]]); mu = np.array([0.05, 0.10])
w = cp.Variable(2)
prob = cp.Problem(cp.Minimize(cp.quad_form(w, S)),       # DCP 凸目标
                  [cp.sum(w) == 1, mu @ w >= 0.08, w >= 0])
prob.solve()                                             # 自动选凸求解器，拿全局最优
print(w.value.round(3), prob.value)                      # 与 scipy 版马科维茨结果对拍
```

### scikit-optimize——贝叶斯优化（昂贵黑盒目标的省预算利器）

> **需 pip install scikit-optimize**。单次评估极贵（仿真/实验/超参）时，高斯过程代理+采集函数把评估次数压到几十次。

```python
# 需 pip install scikit-optimize
from skopt import gp_minimize
def black_box(p):                     # 假装每次评估要 20 分钟的昂贵目标
    return (p[0] - 2)**2 + (p[1] - 3)**2 + 0.1 * np.sin(10 * p[0])
res = gp_minimize(black_box, [(-5.0, 5.0), (-5.0, 5.0)],
                  n_calls=30, n_initial_points=8, random_state=0)
print(res.x, round(res.fun, 4))       # 30 次评估逼近最优 (≈2, 3)
# ⚠️ 维度 >~20 时 GP 代理失效；观测噪声大/目标非平稳时换 Matérn 核，别用默认核硬扛
```

## 反模式（代码级翻车）

- ❌ 目标里有 `abs()` / `max()` / 分段跳变还喂 BFGS/牛顿 → ✅ 换 Nelder-Mead（`method='Nelder-Mead'`）、平滑代理，或给解析次梯度；不可导点处数值差分梯度是错的
- ❌ Adam 忘写偏差修正 `m/(1−β₁ᵗ)` → ✅ 前几百步矩被 0 初值稀释，等效步长失真、表现为"假停滞"；两行补上
- ❌ `linprog` 直接喂 max 目标 → ✅ 取负转 min、结果再取负；对偶影子价格读 `res.ineqlin.marginals`（注意符号约定，最小化形式下为负值）
- ❌ 0/1 背包内层容量正序循环 → ✅ 必须逆序 `range(cap, w-1, -1)`；正序滚动 = 每件可无限选的完全背包，答案静默变错
- ❌ "看起来凸"就直接上局部求解器采信结果 → ✅ 先过保凸运算清单或数值 Hessian 自查；含 rank/整数约束的伪凸 QP 会被静默解成局部解
- ❌ M/M/1 把利用率规划到 0.95，上线后等待时间爆炸 → ✅ W=1/(μ−λ) 在 ρ→1 时发散，按 70–80% 利用率留缓冲
- ❌ SA 跑一次就报"最优解" → ✅ SA 无收敛证书：降温太快退化成贪心，必须多次独立重启取最优
