## 模板代码

### 条件概率与全概率公式 (Conditional Probability & Law of Total Probability)——按已知信息重算概率、分场景加权合并

P(A|B) 是"在 B 前提下"重新定义的概率；全概率公式把复杂事件按分划 {B_i} 拆成"分情况 + 加权"。

```python
import numpy as np
# P(上涨) = Σ P(上涨|超预期)·P(超预期)：分行业拆解再合并
p_up_given_beat = np.array([0.6, 0.5, 0.4])   # P(上涨 | 财报超预期)，按行业
p_beat = np.array([0.2, 0.3, 0.5])            # P(超预期)，Σ=1 构成完备分划
p_up = p_up_given_beat @ p_beat               # 全概率公式
print(f"P(上涨) = {p_up:.3f}")
# ⚠️ 检察官谬误：P(A|B) ≠ P(B|A)，两者相差一个先验比 P(A)/P(B)
p_beat_given_up = p_beat * p_up_given_beat / p_up   # 贝叶斯反转逐行业
print("P(超预期|上涨) =", np.round(p_beat_given_up, 3), "≠ P(超预期) =", p_beat)
```

### 贝叶斯定理 (Bayes' Theorem)——看到新数据后更新判断

后验 = 先验 × 似然 / 证据。稀有事件的后验被基率主导：灵敏度再高，基率极低时报警也不可信。

```python
import numpy as np
prior = 0.01             # 先验：违约率基率 1%
sens, fpr = 0.99, 0.05   # 似然：指标命中率 / 误报率
evidence = sens * prior + fpr * (1 - prior)
post = sens * prior / evidence
print(f"P(违约|报警) = {post:.3f}   （忽视基率会误当成 ≈0.99）")
# ⚠️ 多个小概率连乘进对数空间防下溢：log p 求和后再 exp
logs = np.log([1e-3, 1e-4, 1e-6, 1e-8])
print(f"联合概率 = {np.exp(logs.sum()):.2e}（直接连乘更小就变 0.0）")
```

### 二项分布 (Binomial，含伯努利 Bernoulli)——n 次独立成败试验的成功次数

单次试验即伯努利；E=np、Var=np(1-p)。n 大时组合数溢出、幂次下溢，**一律走对数概率或 scipy 内置**。

```python
from scipy import stats
import numpy as np
n, p = 100_000, 1e-4            # 10 万笔贷款、单笔违约率 0.01%（E=np=10 笔）
k = np.arange(0, 5)
# ⚠️ 别手算 C(n,k)·p^k·(1-p)^(n-k)：math.comb(1e5 级) 上千位整数，p**n 下溢为 0
print("logpmf:", stats.binom.logpmf(k, n, p).round(1))
print(f"P(X≥15) = {stats.binom.sf(14, n, p):.3e}   # sf(k-1)=P(X≥k)，真尾概率")
print(f"E={n*p}, Var={n*p*(1-p):.1f}（p 很小、np 适中时可用泊松近似 λ=np）")
```

### 泊松分布 (Poisson)——单位时间计数 + 过离散诊断

计数数据的默认起点，唯一参数 λ，E=Var=λ。**方差/均值 ≫ 1（过离散）时硬套泊松会低估尾部**，应改负二项。

```python
import numpy as np
from scipy import stats
rng = np.random.default_rng(0)
pois = rng.poisson(3.0, size=1000)                       # 泊松计数样本
over = rng.negative_binomial(1.2, 1.2 / (1.2 + 3), size=1000)   # 均值同为 3、过离散
for name, x in [("泊松样本  ", pois), ("过离散样本", over)]:
    m, v = x.mean(), x.var(ddof=1)
    print(f"{name}: 均值={m:.2f} 方差={v:.2f} 方差/均值={v/m:.2f}")
print("判据：泊松应为 方差/均值 ≈ 1；≫1 时改负二项（如 stats.nbinom）")
```

### 几何分布与超几何分布 (Geometric & Hypergeometric)——首次成功等待数 / 不放回抽样命中数

scipy 的 geom 约定 k 从 1 起（P(X=k)=(1-p)^{k-1}p）。超几何是**不放回**抽样，与二项不等价，仅当抽样比例很小时才近似。

```python
import numpy as np
from scipy import stats
p = 0.1
print(f"P(第5期才首盈) = {stats.geom.pmf(5, p):.4f},  E[等待] = {stats.geom.mean(p):.1f}")
N, K, n = 1000, 100, 50          # 池子 1000 只、命中 100、抽 50（不放回）
hg, bn = stats.hypergeom(N, K, n), stats.binom(n, K / N)
print("超几何 pmf:", np.round(hg.pmf([0, 5, 10]), 4))
print("二项近似:  ", np.round(bn.pmf([0, 5, 10]), 4), "（n/N=5% 小比例才近似）")
# ⚠️ 抽样比例大（n/N > 10%）时必须用超几何，二项会明显失真
```

### 正态分布 (Normal / Gaussian)——连续量与误差建模的默认形态，密度比较用 logpdf

μ、σ² 完全刻画。金融收益率有肥尾与偏度，正态会低估极端损失；**离均值几十 σ 的密度早已下溢为 0，一律用 logpdf**。

```python
from scipy import stats
import numpy as np
mu, sigma = 0.0, 1.0
xs = np.array([0.0, 8.0, 40.0])
print("pdf:   ", stats.norm.pdf(xs, mu, sigma))      # 40σ 处下溢为 0
print("logpdf:", stats.norm.logpdf(xs, mu, sigma))   # ✅ 对数空间完好（≈ -800）
print(f"z_0.975 = {stats.norm.ppf(0.975):.3f}（95% 双侧临界值）")
```

### 指数分布与 Gamma 族 (Exponential & Gamma)——等待时间 / k 段等待之和

指数建模"下次事件等多久"（无记忆），Gamma 是 k 段独立等待之和，χ² 是其形状参数取半整数的特例。**scipy 全族用 scale=1/rate，不是 rate**——参数化分歧是头号翻车点。

```python
from scipy import stats
import numpy as np
lam = 2.0                                # rate λ=2/年
expo = stats.expon(scale=1 / lam)        # ⚠️ scipy 用 scale=1/rate，别把 λ 填进 scale
print(f"P(T>1) = {expo.sf(1):.4f}，对照 e^(-λt) = {np.exp(-lam * 1):.4f}")
gam = stats.gamma(a=3, scale=0.5)        # 形状 k=3（3 段等待之和）、尺度 θ=0.5
print(f"Gamma 均值=kθ={gam.mean():.2f}，方差=kθ²={gam.var():.2f}，P(T≤2)={gam.cdf(2):.4f}")
print("χ² 特例：stats.chi2(df) == gamma(a=df/2, scale=2)")
```

### 三大抽样分布：t、χ²、F (Student's t, Chi-squared & F)——小样本均值/方差推断的基准

t 服务均值推断、χ² 服务方差与拟合优度（期望频数须 ≥5）、F 服务方差比与 ANOVA。

```python
from scipy import stats
print(f"t_0.975(df=9) = {stats.t.ppf(0.975, 9):.3f}（小样本比 z=1.96 宽，别混用）")
print(f"χ²_0.95(df=10) = {stats.chi2.ppf(0.95, 10):.2f}")
print(f"F_0.95(5, 20) = {stats.f.ppf(0.95, 5, 20):.3f}")
# ⚠️ 自由度是最常见翻车点：配对检验 df=n-1；独立等方差 df=n1+n2-2；
#    方差不齐用 Welch，df 由 Welch–Satterthwaite 公式另算（见"假设检验"节）
```

### 大数定律与中心极限定理 (LLN & CLT)——蒙特卡洛误差棒的理论依据

LLN：样本均值随 n 收敛到真值；CLT：波动近似正态，95% 误差半径 ≈ 1.96·σ/√n。**尾指数 ≤2 的肥尾下 √n 律失效**。

```python
import numpy as np
rng = np.random.default_rng(0)
for name, draw in [("均匀(薄尾)", lambda m: rng.uniform(-1, 1, m)),
                   ("t(df=2)肥尾", lambda m: rng.standard_t(2, m))]:
    means = [draw(n).mean() for n in (100, 10_000, 1_000_000)]
    print(name, "样本均值:", [f"{v:+.3f}" for v in means], "← 薄尾万次已收敛，肥尾百万次仍残 0.003")
n, s = 100, 2.0
print(f"CLT 95% 误差半径 ≈ 1.96·σ/√n = {1.96 * s / np.sqrt(n):.3f}")
# ⚠️ 方差不存在（如 df≤2 的 t）时 CLT 收敛极慢甚至失效，改稳健估计/重尾方法
```

### 矩与矩生成函数 (Moments & MGF)——用少数几个数概括分布，MGF 生成各阶矩

原点矩/中心矩给出位置、散度、偏度、峰度；MGF 的 k 阶导数在 t=0 取值即 k 阶矩。**重尾分布的 MGF 在 t>0 可能不存在**，改用特征函数。

```python
import numpy as np
from scipy import stats
from sympy import symbols, exp, diff
t, mu, sig = symbols("t mu sigma")
M = exp(mu * t + sig**2 * t**2 / 2)              # 正态 MGF（存在时）
m4 = diff(M, t, 4).subs({t: 0, mu: 0, sig: 1})
print("正态四阶原点矩 =", m4, "（=3σ⁴）")
x = stats.norm.rvs(size=10_000, random_state=0)
print(f"样本偏度={stats.skew(x):.2f}，超额峰度={stats.kurtosis(x):.2f}（正态 ≈ 0, 0）")
```

### 最大似然估计 (MLE)——选出让观测数据出现概率最大的参数

频率派默认引擎，大样本渐近有效、渐近正态。**对数似然求和防下溢**；闭式有解时先闭式、再数值对照。

```python
import numpy as np
from scipy import optimize, stats
rng = np.random.default_rng(0)
x = rng.normal(loc=1.5, scale=2.0, size=500)
mu_hat, sig_hat = x.mean(), x.std(ddof=0)        # 正态闭式解（ddof=0 才是 MLE）
print(f"闭式: μ̂={mu_hat:.3f}, σ̂={sig_hat:.3f}")
def nll(theta):
    return -stats.norm.logpdf(x, theta[0], theta[1]).sum()   # ⚠️ logpdf 求和防下溢
res = optimize.minimize(nll, x0=[0.0, 1.0], method="Nelder-Mead")
print(f"数值: μ̂={res.x[0]:.3f}, σ̂={res.x[1]:.3f}")
print(f"μ̂ 渐近 SE ≈ σ/√n = {sig_hat / np.sqrt(len(x)):.3f}")
# ⚠️ MLE 只在正则条件下渐近正态，小样本可能严重有偏
```

### 矩估计与无偏性 (Method of Moments & Unbiasedness)——闭式秒出的初值/基准，别神化无偏

令样本矩=总体矩解参数，无需优化。**无偏 ≠ 好**：有偏的收缩估计量（Ridge、James-Stein）常以小偏差换大方差收益。

```python
import numpy as np
rng = np.random.default_rng(0)
x = rng.normal(2, 3, size=40)
print(f"矩估计: μ̂={x.mean():.3f}, σ̂²={x.var(ddof=1):.3f}（真值 2, 9；单次估计有抽样波动）")
s2_0, s2_1 = [], []
for _ in range(20_000):                          # 蒙特卡洛验证无偏性
    s = rng.normal(0, 3, size=10)
    s2_0.append(s.var(ddof=0)); s2_1.append(s.var(ddof=1))
print(f"E[s²(ddof=0)] = {np.mean(s2_0):.3f}（有偏，系统性偏低）")
print(f"E[s²(ddof=1)] = {np.mean(s2_1):.3f}（✅ 无偏 = σ² = 9）")
```

### 置信区间 (Confidence Interval)——量化估计的不确定性

σ 未知、小样本用 t 区间。**"真值 95% 落入这个具体区间"是错误解读**（真值固定，区间随机）；自相关数据套 i.i.d. 公式会低估宽度。

```python
import numpy as np
from scipy import stats
rng = np.random.default_rng(0)
x = rng.normal(0.01, 0.12, size=60)              # 月收益样本（月均 1%）
n = len(x); xbar, s = x.mean(), x.std(ddof=1)
lo, hi = stats.t.interval(0.95, df=n - 1, loc=xbar, scale=s / np.sqrt(n))
print(f"年化收益 {xbar * 12:+.2%}，95% CI [{lo * 12:+.2%}, {hi * 12:+.2%}]")
print("解读：此构造法在重复抽样下 95% 覆盖真值，非'真值在此区间'的概率")
```

### 假设检验与 p 值 (Hypothesis Testing & p-value)——按预设 α 决定拒绝与否

p 值 = 原假设为真时出现当前或更极端数据的概率，**不是"原假设为真的概率"**。方差不齐必须 Welch；批量检验必须多重比较校正。

```python
import numpy as np
from scipy import stats
rng = np.random.default_rng(0)
a = rng.normal(0.0, 1.0, size=30)
b = rng.normal(0.5, 2.0, size=25)                # 两组方差明显不等
t_eq = stats.ttest_ind(a, b)                     # ❌ 默认 Student：假定等方差
t_w = stats.ttest_ind(a, b, equal_var=False)     # ✅ Welch：方差不齐也稳
print(f"Student p={t_eq.pvalue:.3f}  vs  Welch p={t_w.pvalue:.3f} (df={t_w.df:.1f})")
before = rng.normal(size=20)
after = before + 0.4 + rng.normal(scale=0.5, size=20)
print(f"配对检验 df={len(before) - 1}（独立双样本则是 n1+n2-2 或 Welch df）")
print(f"配对 p={stats.ttest_rel(before, after).pvalue:.4f}（同对象前后对比，别拆成独立）")
```

多重比较校正：批量翻策略/测特征时，Bonferroni 最严（控 FWER），FDR（Benjamini-Hochberg）更适合探索性筛选：

```python
import numpy as np
from statsmodels.stats.multitest import multipletests
rng = np.random.default_rng(0)
pvals = rng.uniform(0, 1, size=20)               # 20 个"策略"回测 p 值
pvals[:3] = [0.001, 0.004, 0.009]                # 其中 3 个真信号
for method in ("bonferroni", "fdr_bh"):
    rej, p_adj, *_ = multipletests(pvals, alpha=0.05, method=method)
    print(f"{method:>10}: 拒绝 {rej.sum()} 个, 校正后最小 p={p_adj.min():.4f}")
# ⚠️ 不校正批量检验 0.05×20 ⇒ 期望 1 个纯假阳性"显著"
```

### 方差分析 (ANOVA)——三组及以上均值有无差别

用 F 统计量把总方差分解为组间/组内。**前提：各组近似正态、方差齐性**——先过 Levene，不过关改 Kruskal-Wallis。

```python
import numpy as np
from scipy import stats
rng = np.random.default_rng(0)
groups = [rng.normal(m, 1.0, size=40) for m in (0.2, 0.5, 0.8)]   # 三档因子分组收益
F, p = stats.f_oneway(*groups)
print(f"ANOVA: F={F:.3f}, p={p:.4f}（显著后还要做事后两两比较）")
print(f"Levene 方差齐性 p={stats.levene(*groups).pvalue:.3f}（<0.05 前提不成立）")
kw_H, kw_p = stats.kruskal(*groups)
print(f"非参数备选 Kruskal-Wallis: H={kw_H:.3f}, p={kw_p:.4f}")
```

### Bootstrap 自助法 (Bootstrapping)——对统计量重抽样得标准误与置信区间

对样本有放回重抽样近似统计量的抽样分布，无需分布假设，适合"没有闭式标准误"的统计量（中位数、夏普比、最大回撤）。**时间序列有自相关时必须用块状 bootstrap**。

```python
import numpy as np
rng = np.random.default_rng(0)
x = rng.normal(size=80)
boots = np.array([np.median(x[rng.integers(0, len(x), len(x))])   # 有放回重采样
                  for _ in range(5000)])
lo, hi = np.percentile(boots, [2.5, 97.5])
print(f"中位数 {np.median(x):.3f}，i.i.d. bootstrap 95% CI [{lo:.3f}, {hi:.3f}]")
```

移动块 bootstrap（简版，处理自相关序列）——按块长 L 有放回重拼序列再算统计量，保留短程依赖结构：

```python
import numpy as np
rng = np.random.default_rng(0)
n, L = 250, 20                        # 序列长 n、块长 L（须 ≫ 自相关长度）
e = np.empty(n); e[0] = rng.normal()
for t in range(1, n):
    e[t] = 0.6 * e[t - 1] + rng.normal()        # AR(1) 强自相关
def mbb_ci(x, L, B=2000, seed=0):
    """简版移动块 bootstrap：按块重拼 → 统计量分布分位数"""
    r = np.random.default_rng(seed)
    nb, k = len(x) - L + 1, int(np.ceil(len(x) / L))
    means = np.empty(B)
    for b in range(B):
        starts = r.integers(0, nb, size=k)
        sample = np.concatenate([x[s:s + L] for s in starts])[:len(x)]
        means[b] = sample.mean()
    return np.percentile(means, [2.5, 97.5])
iid = [np.mean(rng.choice(e, size=n, replace=True)) for _ in range(2000)]
print(f"i.i.d. CI  {np.percentile(iid, [2.5, 97.5]).round(3)}（❌ 破坏依赖，偏窄）")
print(f"移动块 CI  {mbb_ci(e, L).round(3)}（✅ 保留自相关结构）")
```

## 反模式（代码级翻车）

- ❌ 大 n 二项手算 `math.comb(n, k) * p**k * (1-p)**(n-k)`（组合数变千位整数、幂次下溢）→ ✅ `stats.binom.logpmf(k, n, p)`，尾概率用 `sf(k-1)`
- ❌ 离均值几十 σ 处直接比较 `pdf` 值，全是 0 分不出高低 → ✅ `logpdf`（对数空间完好，还能跨分布安全相加）
- ❌ 指数/Gamma 把 rate λ 直接填进 scipy 的 `scale` → ✅ `scale=1/rate`；scipy 全族参数化先查文档再套公式
- ❌ 两组方差明显不等还用 `ttest_ind` 默认 Student → ✅ `equal_var=False`（Welch），df 自动走 Welch–Satterthwaite
- ❌ 批量翻 20 个策略看原始 p 值，挑出 3 个"显著"就上 → ✅ `multipletests(pvals, method='fdr_bh')`；不校正 0.05×20 期望出 1 个纯假阳性
- ❌ 计数数据均值方差悬殊仍套泊松，尾部风险被低估 → ✅ 先算 `方差/均值`，≫1 改负二项
- ❌ 自相关序列做 bootstrap 用 i.i.d. 重采样 → ✅ 移动块 bootstrap（块长 ≫ 自相关长度）
