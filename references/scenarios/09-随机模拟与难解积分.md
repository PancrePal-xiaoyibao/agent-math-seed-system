# 🎯 scenario · 随机模拟与难解积分

> **问题信号**：
> - "这个积分/期望没有解析解，维度还挺高"
> - "期权定价 / VaR / 尾部概率怎么估，误差有多大"
> - "跑一次 MC 结果一个样，换个 seed 又一个样"
> - "这个分布没有现成采样器，怎么生成样本"
> - "后验分布没有闭式，参数的不确定性怎么量化"
> - "样本加到多少才够？再加一倍能多一位精度吗"
>
> **典型任务**：
> 1. 高维期权定价：MC 估计 + 标准误报告（求积维度 d≳4 失效换 MC）
> 2. 极端损失尾部概率（1e-6 量级稀有事件）：重要性采样 + ESS 诊断
> 3. 贝叶斯后验无闭式：Metropolis-Hastings 采样 + 收敛诊断（burn-in / R̂ / ESS）
>
> **主推组合**：**蒙特卡洛直接采样（主·高维期望兜底）+ 重要性采样（辅·稀有事件）+ MCMC（辅·贝叶斯后验）** —— 直接采样是高维期望的默认答案（误差 O(1/√N) 且与维度无关）；目标事件太稀有就把样本"搬"到事件发生处（IS）；分布只能求值不能采样或后验无闭式时，构造马尔可夫链去逼近它（MCMC）。
> **备选**：方差缩减（同一精度想省数倍样本时升级） / 拟蒙特卡洛 QMC（中低维要高精度时升级），详表见下。

---

## 🥇 主推工具详解

### A. 蒙特卡洛直接采样 (Direct Monte Carlo)

**为什么适配**："难解积分"的两个出口——维度低走数值求积（`scipy.integrate.quad`），维度高（d≳4）走 MC。MC 的杀手锏是误差 O(1/√N) **与维度无关**：维度灾难面前它不减速，代价只是收敛慢（N 翻 4 倍才多 1 位精度）。期权定价、VaR、贝叶斯预测分布全是这一个动作：从分布抽样本、代函数、取平均。

**一句话 / 输入输出**：用独立样本均值估计期望 E[f(X)]≈(1/N)Σf(xᵢ)，误差 O(1/√N) 且与维度无关；分布与函数 → 估计值 + 标准误。

**陷阱**：
- 不报标准误的 MC 估计不可信——SE = 样本标准差/√N，汇报格式一律"均值 ± 1.96·SE"；
- 稀有事件（尾部概率 1e-6）直接采样效率极低：先粗算命中次数，个位数就该换重要性采样。

**代码入口**：`rng = np.random.default_rng(seed)` 后 `rng.normal(...)` / `rng.choice(...)` 采样；`np.mean(f(x))` 估期望、`np.std(f(x), ddof=1)/np.sqrt(N)` 估标准误 → [recipes/11-蒙特卡洛方法.md](../recipes/11-蒙特卡洛方法.md)

**条目全文**：[domains/D-数值优化与ML与符号/D4-蒙特卡洛方法.md](../domains/D-数值优化与ML与符号/D4-蒙特卡洛方法.md)

### B. 重要性采样 (Importance Sampling)

**为什么适配**：稀有事件的账很好算：估 1e-6 的尾部概率，一百万个样本平均才命中 1 次——直接采样在烧钱。重要性采样的思路是从一个"更容易撞上事件"的提议分布 q 采样，再用权重 p/q 把样本掰回目标分布 p，等于把样本搬到事件发生的地方去。它也是离线策略评估、贝叶斯证据近似的地基。

**一句话 / 输入输出**：从易采样的提议分布 q 采样，用权重 p/q 重加权估计目标分布 p 下的期望；目标密度 p、提议 q → 加权估计，权重期望为 1。

**陷阱**：
- q 的尾部必须比 p **宽**——q 窄则权重无界、方差爆炸，这是 IS 最危险且最安静的死法；
- 诊断必看有效样本量 ESS = 1/Σŵ²（ŵ 为归一化权重）：ESS 掉到几十说明 q 选错了，估计形同虚设。

**代码入口**：从 q 采样（如 `rng.normal(...)`），权重 `w = p(x)/q(x)`，加权平均 `np.sum(w*f(x))/np.sum(w)`，`ESS = 1/np.sum(w_hat**2)` —— 手写权重模板 → [recipes/11-蒙特卡洛方法.md](../recipes/11-蒙特卡洛方法.md)

**条目全文**：[domains/D-数值优化与ML与符号/D4-蒙特卡洛方法.md](../domains/D-数值优化与ML与符号/D4-蒙特卡洛方法.md)

### C. MCMC：Metropolis-Hastings 与 Gibbs

**为什么适配**：贝叶斯推断走到多维参数、非共轭先验这一步，后验就没有闭式了——"知道密度公式却采不出样本"。MCMC 的思路是构造一条以目标后验为平稳分布的马尔可夫链，链走得够久，样本就近似来自后验：均值、区间、HPD 全都从链上算。它是"后验无闭式"信号的唯一主修答案，也是 08 场景档贝叶斯优化里 GP 之外的另一条贝叶斯主线。

**一句话 / 输入输出**：构造以目标后验为平稳分布的马尔可夫链，长时间采样近似后验；非归一化对数后验 → 参数后验样本（均值/区间/HPD）。

**陷阱**：
- 必须诊断收敛（R̂、ESS、trace 图）并丢弃 burn-in——链条看着在走 ≠ 已经收敛；
- 两条链长得像不等于收敛：多峰后验 MH 易卡在一个峰上，换初值多跑几条链互相对照。

**代码入口**：无现成 API —— 手写 MH 模板：提议 `np.random.default_rng().normal(theta, step)`，对数接受率比对 `np.exp(log_p_new - log_p_old)` → [recipes/08-贝叶斯与MCMC.md](../recipes/08-贝叶斯与MCMC.md)

**条目全文**：[domains/C-概率统计与随机/C4-贝叶斯统计.md](../domains/C-概率统计与随机/C4-贝叶斯统计.md)

## 🥈 备选速览（何时升级为主推）

| 工具 | 一句话 | 何时用它当主推 |
|------|--------|---------------|
| 方差缩减：对偶/控制变量 | 用相关性对冲随机性，同一精度省数倍样本 | 直接采样能跑但样本预算紧张时（路径依赖期权、工程仿真）：对偶 `np.mean((f(x)+f(-x))/2)`；控制变量 `f̂ − β(C−E[C])`（β 由样本协方差估）；注意控制变量与目标相关性弱反而增大方差 |
| 拟蒙特卡洛 (QMC) | Sobol/Halton 低差异序列，误差近 O(N⁻¹) | 中低维高精度积分（高维路径期权、全局敏感性分析）：`scipy.stats.qmc.Sobol(d, scramble=True).random(n)`；被积函数不光滑优势缩水；纯确定性点列无误差估计，必须随机化才能报置信区间 |
| 拒绝采样 | 包络密度 Mq 接受-拒绝，从难采样分布生成独立样本 | 目标密度可求值但无现成采样器的**低维**场合（非常规/截断/条件分布）：`random.uniform(a, b)` 从包络采样、`rng.random() < p(x)/(M*q(x))` 判接受；d>5 接受率指数衰减，换 MCMC |
| 先验、后验与共轭先验 | 共轭族后验与先验同族，闭式可算免采样 | 小样本+有领域先验、参数要随数据流式更新时：`scipy.stats.beta(a + successes, b + failures)` 直接取 Beta-Binomial 后验对象（`.mean()`/`.interval()`），Gamma-Poisson 用 `scipy.stats.gamma(a + k, scale=1/(b + T))`——能闭式就别 MCMC |

## ⚠️ 本场景翻车清单

- ❌ 只报均值不报标准误（"MC 算出来是 7.14"） → SE = std(ddof=1)/√N，汇报一律"均值 ± 1.96·SE"；没有 SE 的模拟结果无法与别人对比也无法判断是否收敛。
- ❌ 1e-6 量级尾部概率硬采一百万个样本 → 平均命中 1 次，估计纯靠运气；换重要性采样搬样本，且 q 的尾部必须比 p 宽。
- ❌ IS 加权完直接取数，不看权重健康度 → 先看 ESS=1/Σŵ² 与最大权重；权重被个别样本垄断（ESS 远小于 N）说明 q 选错，结论作废。
- ❌ MCMC 链画出来"看着在走"就停机取样本 → 先丢 burn-in，再看 R̂、trace、ESS；多峰后验换初值多跑几条链，两条链像≠收敛。
- ❌ 低维光滑积分也硬上 MC → d≲3 用 `scipy.integrate.quad(f, a, b)`（自适应求积，收敛快几个量级）；奇异/振荡被积函数先处理奇点再积分。
- ❌ QMC 生成确定性点列直接报置信区间 / 高维（d>5）硬上拒绝采样 → 前者没有随机化就没有误差估计（`scramble=True`）；后者接受率指数衰减，换 MCMC 或变换法。
