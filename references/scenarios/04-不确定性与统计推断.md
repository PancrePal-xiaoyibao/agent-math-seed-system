# 🎯 scenario · 不确定性与统计推断

> **问题信号**：
> - "这个提升是真效果还是运气好 / A/B 测试显著吗"
> - "策略收益是不是显著不等于零 / 跑赢基准是真的吗"
> - "看到这批新数据，我该把原来的判断改成多少"
> - "给这组数据拟合个分布 / 估一下参数，误差多大"
> - "一次筛了几十个因子/策略，怎么避免挑出假冠军"
> - "低基率场景下检测呈阳性，真阳性的概率到底多少"
>
> **典型任务**：
> 1. 判断新策略相对基准的超额收益均值是否显著非零（t 检验 + 批量筛选多重校正）
> 2. 用历史数据拟合分布并给出参数与置信区间（MLE + Bootstrap 区间，如违约率/转化率）
> 3. 稀有事件告警复核：阳性检测结果 × 基率先验 → 贝叶斯后验概率
>
> **主推组合**：**假设检验与 p 值（主）+ MLE / 贝叶斯定理（辅）** —— "显不显著"由假设检验把关（决策门），"参数是多少"由 MLE 回答（估计引擎），"看到新证据信念改多少"由贝叶斯定理回答（更新机制）；三步正好构成"判真伪 → 估参数 → 更新信念"的推断闭环。
> **备选**：Bootstrap（统计量没有闭式标准误时） / 置信区间（问"误差多大"而非"是否非零"时） / ANOVA（比较三组及以上时） / t·χ²·F 抽样分布（手工构造检验查临界值时）

---

## 🥇 主推工具详解

### A. 假设检验与 p 值（Hypothesis Testing & p-value）

**为什么适配**：推断类问题第一句几乎都是"这是真的吗/是不是巧合"——A/B 测试、策略 vs 基准、两组方差谁大。假设检验把"真伪"翻译成可复核的决策程序：在原假设下算出当前或更极端数据的概率，与预设 α 比较；输出统计量、p 值、结论三件套，别人能对着数字复查。

**一句话 / 输入输出**：在"原假设为真"的前提下计算出现当前或更极端数据的概率（p 值），按预设显著性水平 α 决定拒绝与否。输入：原/备择假设 + α → 输出：检验统计量、p 值、决策。

**陷阱**：
- p 值**不是**"原假设为真的概率"，不显著也**不等于**无差异——结论一律写成"在 α=0.05 下拒绝/不拒绝原假设"，同时报效应量；
- 一次检验几十个因子/策略必须先做多重比较校正（Bonferroni/FDR），否则"批量翻策略"必然翻出假阳性冠军。

**代码入口**：`scipy.stats.ttest_ind(a, b, equal_var=False)` —— 独立双样本 t 检验（Welch，默认不假设等方差）；单样本 `scipy.stats.ttest_1samp(x, 0)`，配对 `scipy.stats.ttest_rel(a, b)`；批量校正 `statsmodels.stats.multitest.multipletests(pvals, method='fdr_bh')` → [recipes/06-概率分布与统计检验.md](../recipes/06-概率分布与统计检验.md)

**条目全文**：[domains/C-概率统计与随机/C2-统计推断.md](../domains/C-概率统计与随机/C2-统计推断.md)

### B. 最大似然估计（MLE）

**为什么适配**："给这组数据拟合个分布/模型"是本场景第二常见问法。MLE 是频率派参数估计的默认引擎：scipy 各分布对象自带 `.fit()` 一行出参，大样本下渐近有效且附带标准误——GARCH 参数估计、收益分布拟合、信用模型校准的参数全由它驱动。

**一句话 / 输入输出**：选出让"观测数据出现概率最大"的参数，大样本下渐近有效。输入：数据 + 模型族 → 输出：参数估计值与渐近标准误。

**陷阱**：
- 似然是连乘，必进对数空间（`np.log(pdf).sum()` / log-sum-exp）防下溢，别手写乘积；
- MLE 只在正则条件下渐近正态，小样本可能严重有偏——先跑矩估计（`np.mean`/`np.std`）拿初值和基准，再以 MLE 精化，两边对比着报。

**代码入口**：`scipy.stats.norm.fit(data)` —— 各分布对象自带 `.fit()` 做 MLE（返回 loc/scale 形参）；自定义似然 `scipy.optimize.minimize(neg_loglik, x0)` → [recipes/06-概率分布与统计检验.md](../recipes/06-概率分布与统计检验.md)

**条目全文**：[domains/C-概率统计与随机/C2-统计推断.md](../domains/C-概率统计与随机/C2-统计推断.md)

### C. 贝叶斯定理（Bayes' Theorem）

**为什么适配**："看到新数据后我的判断该改成多少"——低基率告警复核、违约率随新财报更新、策略信号真伪判别，都是先验×似然→后验的信念更新。相比假设检验的"拒绝/不拒绝"二值输出，贝叶斯给出的是更新后的概率本身，天然适配对话式决策与流式数据。

**一句话 / 输入输出**：用"先验×似然"把观察证据转化为后验概率。输入：先验 P(H)、似然 P(E|H)、证据 P(E) → 输出：后验 P(H|E)。

**陷阱**：
- 稀有事件的检测"准确率高"≠后验高——基率（先验）不乘进去，后验被系统性高估（基率谬误）；
- 多个小概率连乘进对数空间防下溢；要的是参数的完整不确定性分布（而非一个数）时，升级到共轭先验闭式更新或 MCMC 采样。

**代码入口**：`posterior = likelihood * prior / evidence` —— 一行比值手写（无直接 API）；小概率连乘用 `np.log` 求和后 `np.exp` 回原域 → [recipes/06-概率分布与统计检验.md](../recipes/06-概率分布与统计检验.md)

**条目全文**：[domains/C-概率统计与随机/C1-概率基础.md](../domains/C-概率统计与随机/C1-概率基础.md)

## 🥈 备选速览（何时升级为主推）

| 工具 | 一句话 | 何时用它当主推 |
|------|--------|---------------|
| Bootstrap 自助法 | 有放回重抽样近似统计量的抽样分布，无需分布假设 | 问题主角是"没有闭式标准误的统计量"（夏普比/最大回撤/中位数）：`scipy.stats.bootstrap((data,), stat, n_resamples=10000)`；注意自相关序列必须换块状 bootstrap |
| 置信区间 | 用区间量化估计的不确定性 | 问的是"这个参数误差多大"而非"是否非零"：`scipy.stats.norm.interval(0.95, loc, sem)`，小样本换 `t.interval`；解读写"重复抽样 95% 的区间盖住真值"，别说成"真值有 95% 在这个区间里" |
| 方差分析（ANOVA） | F 检验比较三组及以上均值是否相同 | 问题从"两组谁高"变成"几档配置/渠道平均表现有没有差别"：`scipy.stats.f_oneway(g1, g2, g3)`；先用 `levene` 查方差齐性，违背就改 `kruskal` 非参数 |
| 三大抽样分布 t·χ²·F | 检验统计量的基准分布，供临界值与 p 值换算 | 手工构造检验或只需要临界值/上尾概率时：`t.ppf(0.975, df)` / `chi2.sf(stat, df)` / `f.sf(stat, d1, d2)`；自由度（配对 vs 独立双样本）别用错 |

## ⚠️ 本场景翻车清单

- ❌ 把 p<0.05 说成"原假设只有 5% 概率为真" → p 值是"原假设为真时出现当前或更极端数据的概率"；表述按"在 α=0.05 下拒绝原假设"，并补效应量与置信区间。
- ❌ 一次筛 50 个因子、直接挑 p 值最小的宣布发现 → 多重比较必出假阳性；先 `multipletests(pvals, method='fdr_bh')` 校正，显著名单以校正后为准。
- ❌ 低基率场景拿检测准确率当真阳性概率 → 检察官谬误；用贝叶斯定理把基率先验乘进去再报后验，P(A|B) 与 P(B|A) 差一个先验比。
- ❌ 对夏普比/最大回撤这类无闭式标准误的统计量硬套正态公式 → 换 `scipy.stats.bootstrap` 重抽样给区间；序列有自相关必须用块状 bootstrap，普通 i.i.d. 重采样会低估不确定性。
- ❌ 置信区间解读成"真值有 95% 概率落在这个区间里" → 真值固定、区间随机；正确说法是"重复抽样构造的区间有 95% 盖住真值"。
- ❌ 小样本直接信 MLE 点估计 → 先用矩估计（样本均值/方差）出基准与初值，MLE 精化后两边对照；对数似然一律求和防下溢。
