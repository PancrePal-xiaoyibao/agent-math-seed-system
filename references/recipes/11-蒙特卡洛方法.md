## 模板代码

### 蒙特卡洛直接采样 (Direct Monte Carlo)——高维期望的兜底，误差 O(1/√N) 与维度无关

用样本均值估期望 E[f(X)] ≈ (1/N)Σf(xᵢ)。维度灾难下的标准答案（求积维度 d≳4 就该换过来），但收敛慢：N 翻 4 倍才多 1 位精度。**不报标准误的 MC 估计不可信**——SE = 样本标准差/√N，报告格式一律"均值 ± 1.96·SE"。

```python
import numpy as np
from scipy.stats import norm
rng = np.random.default_rng(0)                   # 随机一律显式 seed，结果可复现
S0, K, r, sigma, T, n = 100., 105., 0.03, 0.2, 1., 200_000
z = rng.standard_normal(n)                       # 终端采样一步到位（路径依赖题才逐步模拟）
ST = S0 * np.exp((r - 0.5*sigma**2)*T + sigma*np.sqrt(T)*z)
payoff = np.maximum(ST - K, 0.)
disc = np.exp(-r*T)
price, se = disc*payoff.mean(), disc*payoff.std(ddof=1)/np.sqrt(n)   # ✅ 必报标准误
d1 = (np.log(S0/K) + (r + 0.5*sigma**2)*T) / (sigma*np.sqrt(T))
bs = S0*norm.cdf(d1) - K*np.exp(-r*T)*norm.cdf(d1 - sigma*np.sqrt(T))
print(f"MC = {price:.4f} ± {1.96*se:.4f} (95%CI) | BS = {bs:.4f} | CI 覆盖: {abs(price-bs) < 1.96*se}")
# 输出: MC = 7.1398 ± 0.0550 | BS = 7.1281 | 覆盖 True
# ⚠️ 稀有事件（尾部概率 1e-6 量级）直接采样效率极低——先算命中次数，个位数就该换重要性采样
```

### 重要性采样 (Importance Sampling)——从易采样的 q 采，用权重 p/q 重加权

稀有事件/尾部概率的主力：把样本搬到"事件发生的地方"去。代价是估计质量完全由提议分布 q 决定——**q 的尾部必须比 p 宽**，q 窄则权重无界（最危险情形）。诊断必看两个量：有效样本量 ESS = (Σw)²/Σw²，以及最大权重。

```python
import numpy as np
from scipy.stats import norm
rng = np.random.default_rng(0)
n = 100_000
print("目标: 估计 E[Z^2] = 1（p = N(0,1)），考察提议分布 q 的选择")
for s, tag in ((1.2, "q=N(0,1.2²) 尾部更宽"), (0.8, "q=N(0,0.8²) 尾部更窄")):
    z = s * rng.standard_normal(n)               # 从 q = N(0, s²) 采样
    w = norm.pdf(z) * s / norm.pdf(z / s)        # 权重 w = p(z)/q(z)，期望为 1
    est = (w * z**2).mean()
    ess = w.sum()**2 / (w**2).sum()              # ✅ 有效样本量 ESS
    print(f"{tag}: 估计 {est:.4f}  最大权重 {w.max():.1f}  ESS = {ess/n:.0%}")
# 宽尾: 估计 0.998 / 最大权重 1.2 / ESS 95%；窄尾: 最大权重 35.7 / ESS 83%
# ⚠️ 窄尾 q 的单个样本能贡献 35 倍权重——换 seed 就可能大幅跑偏；ESS 掉出 80% 即警报，换尾部更宽的 q
```

### 拒绝采样 (Rejection Sampling)——密度可求值但没现成采样器时

用包络 M·q 盖住目标（未归一化）密度，提议点按 u < p(z)/(M·q(z)) 接受，接受率 = 1/M。截断分布/条件分布的常用路线。**包络常数 M 是命门：取小了分布悄悄偏差且极难察觉**。

```python
import numpy as np
from scipy.stats import norm
rng = np.random.default_rng(0)
a, b = -1.0, 2.0                                 # 目标: N(0,1) 截断在 [a,b]（差常数因子无妨）
M = 1.0 / (norm.cdf(b) - norm.cdf(a))            # 包络常数: sup p_unnorm/q = 1/(Φ(b)-Φ(a))
acc, n_prop = [], 0
while sum(map(len, acc)) < 20_000:
    z = rng.standard_normal(8192)                # 提议 q = N(0,1)
    u = rng.uniform(size=8192)
    ok = (z >= a) & (z <= b) & (u * M <= 1.0)    # 接受条件 u < p(z)/(M·q(z))
    acc.append(z[ok]); n_prop += 8192
s = np.concatenate(acc)
true_mean = (norm.pdf(a) - norm.pdf(b)) / (norm.cdf(b) - norm.cdf(a))
print(f"接受率 {len(s)/n_prop:.3f}（理论 (Φ(b)-Φ(a))² = {(norm.cdf(b)-norm.cdf(a))**2:.3f}）")
print(f"样本均值 {s.mean():.4f} vs 解析截断正态均值 {true_mean:.4f}")
# 接受率 0.673 ≈ 理论 0.670；样本均值 0.2297 ≈ 解析 0.2296
# ⚠️ M 按 sup p/q 逐点核对（宁大勿小）；高维(d>5)接受率指数衰减，改换 MCMC 或变换法
```

### 方差缩减：对偶变量与控制变量 (Antithetic & Control Variates)——同精度省数倍样本

用相关性对冲随机性：对偶变量把 f(Z) 与 f(−Z) 配对平均（单调 payoff 上两者负相关）；控制变量用期望已知的伴生量 C 修正估计，最优系数 β* = Cov(f,C)/Var(C) 由数据估出。下面同一批样本喂三种估计量，公平对比。

```python
import numpy as np
rng = np.random.default_rng(0)
S0, K, sigma, T, n = 100., 100., 0.2, 1., 100_000
z = rng.standard_normal(n)
ST = S0 * np.exp(-0.5*sigma**2*T + sigma*np.sqrt(T)*z)
pay = np.maximum(ST - K, 0.)
se0 = pay.std(ddof=1) / np.sqrt(n)
anti = 0.5*(np.maximum(S0*np.exp(-0.5*sigma**2*T + sigma*np.sqrt(T)*z) - K, 0.)
          + np.maximum(S0*np.exp(-0.5*sigma**2*T - sigma*np.sqrt(T)*z) - K, 0.))
se_a = anti.std(ddof=1) / np.sqrt(n)             # 对偶: f(Z) 与 f(-Z) 配对平均
C = ST - S0                                      # 控制变量: E[ST] = S0 已知
beta = np.cov(pay, C)[0, 1] / C.var()            # ✅ 最优系数由数据估出
se_c = (pay - beta*C).std(ddof=1) / np.sqrt(n)
print(f"SE: 直接 {se0:.4f} | 对偶 {se_a:.4f}(等效样本x{se0**2/se_a**2:.1f}) | 控制 {se_c:.4f}(x{se0**2/se_c**2:.1f})")
# 输出: 0.0416 | 0.0234(x3.1) | 0.0190(x4.8)——同精度下省 3-5 倍样本
# ⚠️ 控制变量与目标弱相关/负相关反而放大方差——先估相关系数再上；对偶也要求 f 对称性匹配
```

### 拟蒙特卡洛 (Quasi-Monte Carlo, QMC)——低差异序列，误差近 O(N⁻¹)

Sobol/Halton 确定性点列铺得更匀，光滑被积函数上标准误比伪随机小 1-2 个量级。**纯确定性点列没有误差估计——必须随机化（scramble，RQMC）重复多次才能报置信区间**。

```python
import numpy as np
from scipy.stats import norm, qmc
d, n, reps = 4, 1024, 16                         # d 维积分: E[exp(0.1·(Z1+..+Z4))] = e^{0.02}
exact = np.exp(0.5 * 0.01 * d)
f = lambda u: np.exp(0.1 * norm.ppf(u).sum(axis=1))   # 均匀点 → 正态样本 → 被积函数
rng = np.random.default_rng(0)                   # 统一 seed：scramble 与 MC 全部可复现
vals = np.array([f(qmc.Sobol(d=d, scramble=True, seed=rng).random(n)).mean()   # ✅ scramble 随机化
                 for _ in range(reps)])                               # 同一 rng 连续推进=独立随机化
mc = f(rng.uniform(size=(reps*n, d)))
print(f"精确  {exact:.6f}")
print(f"RQMC  {vals.mean():.6f} ± {vals.std(ddof=1)/np.sqrt(reps):.1e}")
print(f"MC    {mc.mean():.6f} ± {mc.std(ddof=1)/np.sqrt(reps*n):.1e}")
# RQMC ±2.8e-05 vs MC ±1.6e-03：SE 小约两个量级
# ⚠️ scramble=False 的纯 Sobol 不能报精度；被积函数不光滑时 QMC 优势大幅缩水
```

## 反模式（代码级翻车）

- ❌ MC 只报点估计不报标准误 → ✅ 一律"均值 ± 1.96·SE"，SE = `std(ddof=1)/sqrt(n)`；没有 SE 的 MC 估计无法验收
- ❌ 稀有事件直接采样硬砸样本数（P≈1e-5 时命中个位数）→ ✅ 重要性采样把样本搬进尾部；先估命中率，个位数命中就该换方法
- ❌ 提议分布 q 随手取，从不看权重 → ✅ q 尾部必须比 p 宽；报告 ESS 与最大权重，ESS 掉出 80% / 权重跨数量级即换 q
- ❌ 拒绝采样的包络常数 M 凭感觉给小 → ✅ M = sup p/q 逐点核对（M 不足则分布偏差且难察觉）；看接受率是否等于理论 1/M
- ❌ 控制变量随机挑一个"感觉相关"的量 → ✅ 先估 β* = Cov(f,C)/Var(C) 与相关系数；弱相关/负相关反而放大方差
- ❌ 确定性 Sobol 点列直接当精度报 → ✅ `scramble=True` + 多次独立重复报标准误（RQMC）；不光滑被积函数退回伪随机 MC
