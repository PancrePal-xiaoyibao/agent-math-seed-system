## 模板代码

### 矩阵运算 (Matrix Operations)——一切线性变换的记法

矩阵乘法是线性映射的复合，`@` 是唯一正确算子。动手前先核对维度内标，写完怀疑结果时先查"是否默认了可交换"。

```python
import numpy as np
A = np.array([[1., 2.], [3., 4.]])
B = np.array([[0., 1.], [1., 0.]])
print(A @ B)                            # 矩阵乘 = 行×列 = 映射复合
print(not np.allclose(A @ B, B @ A))    # ⚠️ 乘法不可交换：AB ≠ BA，顺序即语义
v = np.array([1., 1.])
print(A @ v, A.T)                       # 矩阵-向量乘、转置
# ⚠️ 维度先行：(m×n)@(n×p) 内标一致才可乘，维度不匹配是最常见报错
```

### 秩与行列式 (Rank & Determinant)——判"信息量"与可逆性

数值判秩只能靠 SVD 奇异值阈值（`matrix_rank` 内部就是这么做的）；`det` 是体积缩放因子，不是秩的裁判。

```python
import numpy as np
rng = np.random.default_rng(0)
A = rng.normal(size=(5, 5))
A[:, 3] = A[:, 0] + 2 * A[:, 1]         # 人为制造秩亏（第 4 列是前两列的线性组合）
print(np.linalg.matrix_rank(A))         # ✅ 数值判秩：SVD 奇异值阈值
print(f"{np.linalg.det(A):.2e}")        # ⚠️ 浮点 det"接近 0"不可靠，别拿它判秩
```

### 逆矩阵 (Inverse)——数学上有，数值上少用

标准写法（真的需要逆矩阵本身时）：

```python
import numpy as np
rng = np.random.default_rng(0)
A = rng.normal(size=(4, 4)) + 4 * np.eye(4)
Ainv = np.linalg.inv(A)                 # 仅用于符号推导、小规模精确需求、变换的逆操作
print(np.allclose(A @ Ainv, np.eye(4)))
```

陷阱规避写法（解 Ax=b 时——本卡最高频陷阱）：

```python
import numpy as np
from scipy.linalg import hilbert
H = hilbert(10); x_true = np.ones(10); b = H @ x_true
x_solve = np.linalg.solve(H, b)         # ✅ LU+选主元直接解方程，快且稳
x_inv = np.linalg.inv(H) @ b            # ❌ "先 inv 再乘"是经典反模式：慢且更不稳
print(f"solve 相对误差 {np.linalg.norm(x_solve - x_true) / np.sqrt(10):.1e}")
print(f"inv    相对误差 {np.linalg.norm(x_inv - x_true) / np.sqrt(10):.1e}")
```

### Moore–Penrose 伪逆 (Pseudoinverse)——秩亏/长方矩阵的万能解

欠定、超定、秩亏系统统一交给 `pinv`：它给最小范数最小二乘解，是手写 `(XᵀX)⁻¹Xᵀy` 的安全替代。

```python
import numpy as np
rng = np.random.default_rng(0)
A = rng.normal(size=(3, 3))
A[:, 2] = A[:, 0] + A[:, 1]             # 秩 2 ⇒ 不可逆
b = np.array([1., 0., -1.])
x = np.linalg.pinv(A) @ b               # ✅ 解不唯一时给最小范数解
x_lstsq, *_ = np.linalg.lstsq(A, b, rcond=None)
print(x.round(3), np.allclose(x, x_lstsq))
# ⚠️ pinv 内部经 SVD 截断小奇异值，rcond 阈值选取影响结果
```

### 特征值分解 (Eigendecomposition)——看长期行为与主方向的谱透镜

对称阵必须用 `eigh`（更快、实特征值、正交特征向量）；一般方阵用 `eig`，并预期复数特征值。

```python
import numpy as np
rng = np.random.default_rng(0)
S = rng.normal(size=(4, 4))
A_sym = S + S.T                         # 对称阵（协方差、核矩阵都长这样）
w, V = np.linalg.eigh(A_sym)            # ✅ 对称专用：实特征值 + 正交特征向量
print(w.round(3), np.allclose(V.T @ V, np.eye(4)))
B = np.array([[0., -1.], [1., 0.]])     # 非对称（90° 旋转）
print(np.linalg.eigvals(B))             # ⚠️ 非对称阵特征值可为复数（这里 ±i）
```

### 奇异值分解 (SVD)——任意矩阵的谱分析 + 最优低秩近似

按奇异值从大到小截断即得最优低秩近似；误差有闭式，截断阈值按噪声水平定。

```python
import numpy as np
rng = np.random.default_rng(0)
U0, _ = np.linalg.qr(rng.normal(size=(40, 3)))
V0, _ = np.linalg.qr(rng.normal(size=(20, 3)))
X = U0 @ np.diag([50., 20., 5.]) @ V0.T + 0.1 * rng.normal(size=(40, 20))  # 秩3+噪声
U, s, Vt = np.linalg.svd(X, full_matrices=False)
k = 3
Xk = U[:, :k] @ np.diag(s[:k]) @ Vt[:k]         # ⚠️ 截断阈值按噪声水平定，不是越小越好
err = np.linalg.norm(X - Xk)
print(np.sqrt(np.sum(s[k:] ** 2)), err)         # ✅ 最优近似误差 = 丢弃奇异值平方和开根
print(f"压缩比 {X.size / (U[:, :k].size + k + Vt[:k].size):.1f}x")
```

### LU / QR / Cholesky 分解 (Matrix Factorizations)——三大数值分解选型

选型口诀：解方程组用 LU（一个分解喂多个右端项），拟合/回归用 QR（正交最稳），对称正定用 Cholesky（最快）。

```python
import numpy as np
from scipy.linalg import lu_factor, lu_solve
rng = np.random.default_rng(0)
A = rng.normal(size=(50, 50)) + 10 * np.eye(50)
lu, piv = lu_factor(A)                  # 分解一次
for _ in range(2):                      # 多个右端项复用同一分解
    b = rng.normal(size=50)
    x = lu_solve((lu, piv), b)          # ✅ LU+选主元：通用解方程组
Q, R = np.linalg.qr(A)
print(np.abs(Q @ Q.T - np.eye(50)).max(), np.abs(Q @ R - A).max())
# QR 正交性最好，是回归/拟合求解的底座
```

Cholesky 单独示教——**报错是诊断信号，不是 bug**：

```python
import numpy as np
rng = np.random.default_rng(0)
B = rng.normal(size=(6, 4))
A_spd = B @ B.T + np.eye(6)             # BᵀB+I 形式 ⇒ 对称正定
L = np.linalg.cholesky(A_spd)
print(np.abs(L @ L.T - A_spd).max())    # ✅ SPD 矩阵最快的分解
A_bad = B @ B.T
A_bad[0, 0] -= 10                       # 人为破坏正定性
try:
    np.linalg.cholesky(A_bad)
except np.linalg.LinAlgError:
    print("LinAlgError：矩阵非正定 —— 诊断信号：查数据/协方差/加正则，别 try 完装没事")
```

### 二次型与正定性 (Quadratic Form & Positive Definiteness)——极值与凸性的判据

Hessian 正定 ⇔ 局部极小；判定工具是特征值（全正）或顺序主子式，正定性检查也等价于"Cholesky 能不能过"。

```python
import numpy as np
H = np.array([[2., -1.], [-1., 2.]])    # f = x²+y²−xy 的 Hessian
print(np.linalg.eigvalsh(H))            # 全 >0 ⇒ 正定 ⇒ 原点是局部极小
x = np.array([1., -2.])
print(x @ H @ x > 0)                    # 二次型 xᵀAx 在任意非零 x 上为正
A_bad = np.array([[1., 2.], [2., 1.]])
print(np.linalg.eigvalsh(A_bad))        # ⚠️ 不定阵：一正一负 ⇒ 鞍点信号
```

### 投影与最小二乘 (Projection & Least Squares)——把"不可达"化为"最近可达"

投影 = 列空间里离 b 最近的点，判据是残差与列空间正交。

```python
import numpy as np
rng = np.random.default_rng(0)
A = np.column_stack([np.ones(8), np.arange(8.)])   # 列空间：常数 + 线性趋势
b = rng.normal(size=8)
p = A @ np.linalg.lstsq(A, b, rcond=None)[0]       # 投影点 = 列空间中的最近点
print(np.abs(A.T @ (b - p)).max())                 # 残差⊥列空间 ⇔ 正规方程成立
# ⚠️ 手写投影阵 A(AᵀA)⁻¹Aᵀ 要求列满秩，且组装 AᵀA 会平方条件数
```

最小二乘（域 D 交叉条目，另见 [domains/D1](../domains/D-数值优化与ML与符号/D1-数值分析基础.md)）——**永远别按正规方程求逆**：

```python
import numpy as np
from scipy.linalg import hilbert
H = hilbert(9)                                      # cond≈5e11 的病态设计阵
b = H @ np.ones(9)
xn = np.linalg.solve(H.T @ H, H.T @ b)              # ❌ 正规方程：条件数被平方
xl = np.linalg.lstsq(H, b, rcond=None)[0]           # ✅ SVD/QR 求解
print(f"cond(H)={np.linalg.cond(H):.0e}  cond(HᵀH)={np.linalg.cond(H.T @ H):.0e}")
print(f"正规方程误差 {np.linalg.norm(xn - 1):.2f}   lstsq 误差 {np.linalg.norm(xl - 1):.1e}")
# 打印的 cond(HᵀH)≈1e17 是 float64 舍入地板（组装 HᵀH 的舍入已淹没小奇异值）；
# 精确算术里 κ(HᵀH)=κ(H)²≈2.5e23 —— 舍入反而"遮住"了问题的真实病态规模
```

### 范数与条件数 (Norms & Condition Number)——"这个数值答案还能信几位"

范数定义长度（正则化选型：L1 稀疏 / L2 平滑）；条件数 κ(A)=σmax/σmin 度量扰动放大倍数，是"问题本身的病态度"。

```python
import numpy as np
rng = np.random.default_rng(0)
A = rng.normal(size=(4, 4)); v = A[:, 0]
print(np.linalg.norm(v), np.linalg.norm(v, 1), np.linalg.norm(v, np.inf))
print(np.linalg.norm(A, 'fro'), np.linalg.norm(A, 2))   # 谱范数 = 最大奇异值
print(f"cond = {np.linalg.cond(A):.2f}")                # κ = σmax/σmin（SVD 法，别用 inv 手算）
```

条件数与有效数字（域 D 交叉条目，另见 [domains/D1](../domains/D-数值优化与ML与符号/D1-数值分析基础.md)）——κ≈10^k ⇒ 解约损失 k 位有效数字：

```python
import numpy as np
from scipy.linalg import hilbert
for n in (6, 8, 10):
    H = hilbert(n)
    x = np.linalg.solve(H, H @ np.ones(n))
    err = np.linalg.norm(x - 1) / np.sqrt(n)
    print(f"n={n}  κ={np.linalg.cond(H):.1e}  相对误差={err:.1e}")
# κ 每涨 1000 倍，误差同步涨 1000 倍：报答案前先看 κ，决定保留几位
```

### 共轭梯度法 (Conjugate Gradient，域 D 交叉条目，另见 [domains/D1](../domains/D-数值优化与ML与符号/D1-数值分析基础.md))——大规模稀疏 SPD 系统标配

只需矩阵-向量乘，不碰 O(n³) 分解；病态时预处理（Preconditioning）是收敛快慢的命门。

```python
import numpy as np
from scipy.sparse import diags
from scipy.sparse.linalg import cg
n = 400
d = 10.0 ** np.linspace(0, 4, n)        # 对角跨度 1e4 ⇒ κ≈1e4
A = diags([d, -0.01 * np.ones(n - 1), -0.01 * np.ones(n - 1)], [0, 1, -1], format='csr')
b = np.ones(n)
it0 = []
cg(A, b, rtol=1e-8, maxiter=5000, callback=lambda x: it0.append(1))
M = diags([1.0 / d], [0], format='csr') # Jacobi 预处理（对角缩放）
# ⚠️ scipy 约定 M ≈ inv(A)：传成 A 的对角本身会把病态反向放大
it1 = []
x, info = cg(A, b, M=M, rtol=1e-8, maxiter=5000, callback=lambda x: it1.append(1))
print(len(it0), "次迭代 →", len(it1), "次迭代（info =", info, "）")
# ⚠️ A 非 SPD 时 CG 会静默不收敛：先用 Cholesky 验 SPD，非对称换 GMRES/bicgstab
```

### 特征值算法概览 (Eigenvalue Algorithms，域 D 交叉条目，另见 [domains/D1](../domains/D-数值优化与ML与符号/D1-数值分析基础.md))——只要极值就别做全谱

Lanczos/Arnoldi（`eigsh`/`eigs`）只算你要的那几个特征值，复杂度与矩阵-向量乘同阶。

```python
import numpy as np
from scipy.sparse import diags
from scipy.sparse.linalg import eigsh
n = 1000
A = diags([-np.ones(n - 1), 2 * np.ones(n), -np.ones(n - 1)], [-1, 0, 1], format='csr')
lam = eigsh(A, k=1, which='SA', return_eigenvectors=False)   # 最小特征值（Lanczos）
print(lam, 2 * (1 - np.cos(np.pi / (n + 1))))                # 数值 vs 理论 ≈ (π/(n+1))²
# ⚠️ 只要极值特征值（谱聚类/稳定性分析）就别 np.linalg.eig 全谱分解 O(n³)
# ⚠️ 顶谱挤在一起（本例 n=1000 顶谱相对间隙仅 ~1e-5 量级）时 Lanczos 收敛极慢：
#    求最大特征值可能吃满 maxiter，改求最小端（'SA'）或移位反转（sigma=目标值）
```

## 反模式（代码级翻车）

- ❌ `np.linalg.inv(A) @ b` 解方程组 → ✅ `np.linalg.solve(A, b)`（LU+选主元，更快更稳）
- ❌ 组装正规方程 `solve(A.T @ A, A.T @ b)` 做最小二乘（条件数被平方，病态问题直接报废）→ ✅ `np.linalg.lstsq(A, b, rcond=None)`（SVD 求解）
- ❌ `abs(det(A)) < 1e-12` 判奇异/判秩 → ✅ `np.linalg.matrix_rank(A)` 或看 `cond(A)`（浮点 det 不可靠）
- ❌ Cholesky 报错后 `try/except pass` 继续往下算 → ✅ 报错 = "矩阵非正定"的诊断信号：查协方差、加正则 `+εI`，或改用特征值判定
- ❌ 不管 κ 多大直接报 16 位结果 → ✅ 先算 `cond`，κ≈10^k 时声明"仅约 16−k 位有效数字可信"
- ❌ 对非对称/不定矩阵硬上 CG，不收敛就怪库 → ✅ 先 `cholesky` 验 SPD；预处理时 `M ≈ inv(A)`（scipy 约定），传反了会越预处理越病态
