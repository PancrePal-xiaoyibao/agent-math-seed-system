## 模板代码

### 线性回归与 OLS 诊断 (Linear Regression / OLS)——量化 y 与各因子的边际效应

系数无偏 ≠ 推断可信：线性/独立/同方差/正态假设破坏时，标准误先失真。异方差用稳健标准误，自相关用 Newey-West HAC。

```python
import numpy as np
import statsmodels.api as sm
rng = np.random.default_rng(0)
n = 200
x = rng.normal(size=n)
y = 1 + 2 * x + rng.normal(scale=1 + 2 * np.abs(x), size=n)   # 人造异方差
X = sm.add_constant(x)
ols = sm.OLS(y, X).fit()                     # 经典 SE：异方差下失真
rob = sm.OLS(y, X).fit(cov_type='HC3')       # ✅ 稳健 SE（小样本首选 HC3）
print("经典 bse:", np.round(ols.bse, 3))     # 系数仍无偏，但 SE 不可信
print("HC3   bse:", np.round(rob.bse, 3))
print(rob.params.round(3), "R² =", rob.rsquared.round(3))
```

诊断三件套：自相关（Durbin-Watson）→ HAC；残差正态性（Jarque-Bera）；共线性（VIF）：

```python
import numpy as np
import statsmodels.api as sm
from statsmodels.stats.stattools import durbin_watson, jarque_bera
from statsmodels.stats.outliers_influence import variance_inflation_factor
rng = np.random.default_rng(1)
n = 150
x1 = rng.normal(size=n)
x2 = 0.9 * x1 + 0.1 * rng.normal(size=n)     # 高度共线
e = np.empty(n); e[0] = rng.normal()
for t in range(1, n):
    e[t] = 0.7 * e[t - 1] + 0.5 * rng.normal()   # ⚠️ 自相关噪声：经典 SE 失效
y = 1 + 2 * x1 + 0.5 * x2 + e
X = sm.add_constant(np.column_stack([x1, x2]))
fit = sm.OLS(y, X).fit(cov_type='HAC', cov_kwds={'maxlags': 5})   # ✅ Newey-West
print(fit.params.round(3))
print(f"DW = {durbin_watson(fit.resid):.2f}（≈2 无自相关，≪2 正自相关）")
print(f"JB p 值 = {jarque_bera(fit.resid)[1]:.3f}（残差正态性）")
print("VIF =", [f"{variance_inflation_factor(X, i):.1f}" for i in (1, 2)], "（>10 共线警报）")
```

### 逻辑回归 (Logistic Regression)——预测事件发生概率

sigmoid 把线性组合映射为概率，系数可解释为对数几率变化。数据完全可分时 MLE 无有限解——**必须靠正则化收住**。

```python
import numpy as np
from sklearn.linear_model import LogisticRegression
rng = np.random.default_rng(0)
X = rng.normal(size=(60, 2))
y = (X[:, 0] + X[:, 1] > 0).astype(int)      # 完全可分数据
lr_inf = LogisticRegression(C=np.inf, max_iter=1000).fit(X, y)       # ❌ 无正则：MLE 发散
lr_reg = LogisticRegression(C=1.0, max_iter=1000).fit(X, y)          # ✅ 默认 L2 正则
print(f"无正则 |coef|max = {np.abs(lr_inf.coef_).max():.0f}（随迭代膨胀——可分 ⇒ MLE 无有限解；若见 ConvergenceWarning 只是迭代预算不够，不是该调学习率）")
print(f"L2     |coef|max = {np.abs(lr_reg.coef_).max():.2f}")
print(lr_reg.predict_proba(X[:2]).round(3))
# ⚠️ 类别不平衡时看 AUC/PR 与校准曲线，别看 accuracy
```

### 正则化的统计视角：Ridge 与 Lasso (Ridge & Lasso)——抗共线与变量选择

L2（Ridge）压缩系数抗共线性，L1（Lasso）产生稀疏解兼做变量选择。**惩罚只对同量纲的系数才公平**——先标准化再惩罚，λ 交给交叉验证。

```python
import numpy as np
from sklearn.linear_model import RidgeCV, LassoCV, Lasso
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
rng = np.random.default_rng(0)
n = 150
U = rng.normal(size=(n, 6))
scales = np.array([1., 1., 10., 100., 1000., 10000.])    # 同一份信息，六种量纲
X = U * scales                             # 原始量纲悬殊
beta_std = np.array([2.0, 0, -1.5, 0, 0, 3.0])
y = U @ beta_std + rng.normal(scale=0.1, size=n)
ridge = make_pipeline(StandardScaler(), RidgeCV(alphas=np.logspace(-3, 3, 25))).fit(X, y)
lasso = make_pipeline(StandardScaler(), LassoCV(cv=5)).fit(X, y)
lasso_big = make_pipeline(StandardScaler(), Lasso(alpha=0.1)).fit(X, y)
print("Ridge 系数（标准化空间）:", np.round(ridge[-1].coef_, 2))   # L2 压缩、不出精确零
print("Lasso 系数（标准化空间）:", np.round(lasso[-1].coef_, 2))   # CV 选 λ：噪声列 ≈ 0
print("加大 λ 后:          ", np.round(lasso_big[-1].coef_, 2))   # L1 稀疏：噪声列精确 = 0
print("λ 由交叉验证定:", round(float(lasso[-1].alpha_), 4))
print("还原原始量纲:", np.round(lasso[-1].coef_ / lasso[0].scale_, 4))
# ⚠️ pipeline 里 coef_ 是标准化空间的：解释/部署必须除回 scale_，否则量纲错 10^4 倍
```

### 主成分分析 (Principal Component Analysis, PCA)——高维相关数据降维

对协方差（或相关）矩阵做谱分解，把相关变量压成少数互不相关的主成分。量纲不齐必须先标准化（= 用相关阵），否则高方差变量垄断 PC1。

```python
import numpy as np
from sklearn.decomposition import PCA
from sklearn.preprocessing import StandardScaler
rng = np.random.default_rng(0)
f = rng.normal(size=200)
X = np.column_stack([f + 0.6 * rng.normal(size=200),
                     f + 0.6 * rng.normal(size=200),
                     1e5 * rng.normal(size=200)])     # 第 3 列：纯噪声但量纲巨大
pca_raw = PCA().fit(X)
pca_std = PCA().fit(StandardScaler().fit_transform(X))   # ✅ 标准化 = 用相关阵做 PCA
print("原始量纲方差占比:", pca_raw.explained_variance_ratio_.round(3))
print("标准化方差占比:  ", pca_std.explained_variance_ratio_.round(3))
print("PC1 载荷:", pca_std.components_[0].round(2))       # 抓住前两列的公共因子
# ⚠️ 成分本身无业务含义，解释要克制（收益率曲线的"水平/斜率/曲率"是例外而非通例）
```

### 聚类的统计原理：K-means 与高斯混合 (K-means & GMM)——硬分配与软分配

K-means 最小化到质心的距离平方和（硬标签）；GMM 用 EM 估计混合高斯的软归属概率。两者都对初值和量纲敏感，k 不能拍脑袋。

```python
import numpy as np
from sklearn.cluster import KMeans
rng = np.random.default_rng(0)
X = np.vstack([rng.normal(c, 0.8, size=(80, 2)) for c in ([-3, 0], [0, 3], [3, 0])])
km = KMeans(n_clusters=3, n_init=10, random_state=0).fit(X)   # ✅ 多重启防坏初值
print("各簇样本数:", np.bincount(km.labels_))
inertia = [KMeans(n_clusters=k, n_init=10, random_state=0).fit(X).inertia_
           for k in range(1, 6)]
print([round(v) for v in inertia])       # 肘部法选 k：k=3 后骤降趋缓
# ⚠️ K-means 只适合凸球形簇；特征量纲必须先统一
```

GMM 侧：BIC 选 k + 软分配（EM 对初值敏感，`n_init` 重启）：

```python
import numpy as np
from sklearn.mixture import GaussianMixture
rng = np.random.default_rng(0)
X = np.vstack([rng.normal(c, 0.8, size=(80, 2)) for c in ([-3, 0], [0, 3], [3, 0])])
bics = [GaussianMixture(k, n_init=5, random_state=0).fit(X).bic(X) for k in range(1, 8)]
print("BIC 最优 k =", int(np.argmin(bics)) + 1)   # ✅ 模型选择交给 BIC，别拍脑袋
gmm = GaussianMixture(n_components=3, n_init=5, random_state=0).fit(X)
print(gmm.predict_proba(X[:2]).round(3))          # 软分配：后验归属概率
# ⚠️ EM 只保证局部最优，可能收敛到边界/鞍点；诊断时看归属概率是否"一家独大"
```

## 反模式（代码级翻车）

- ❌ 异方差/自相关数据直接报 OLS 经典标准误 → ✅ `.fit(cov_type='HC3')`（异方差）/ `.fit(cov_type='HAC', cov_kwds={'maxlags': 5})`（Newey-West）
- ❌ 完全可分数据上 `C=np.inf`/`penalty=None` 硬拟合，看到系数爆炸去调学习率 → ✅ 用默认 L2 正则（C=1.0）：可分 ⇒ MLE 无有限解，发散是数学性质不是工程故障
- ❌ Ridge/Lasso 直接喂原始量纲，最该保住的大尺度特征被惩罚得最狠 → ✅ `make_pipeline(StandardScaler(), 模型)`；λ 交给 `RidgeCV`/`LassoCV`，不拍脑袋
- ❌ 混合量纲数据直接 `PCA().fit(X)`，高方差变量垄断 PC1 → ✅ 先 `StandardScaler`（等价于用相关阵做 PCA）再分解
- ❌ KMeans 用默认单次初始化就采信结果 → ✅ `n_init=10` 多重启取最优；k 用肘部法/轮廓系数/GMM-BIC 定
- ❌ 类别不平衡任务只看 accuracy → ✅ `predict_proba` + AUC/PR 与校准曲线
