## 模板代码

### 符号求导·化简·解方程·级数 (SymPy: diff / simplify / solve / series)——推导演算、校验手算、给数值代码生成精确公式

符号级精确结果，不是浮点近似。四件套覆盖 90% 推导需求：求导、化简、解析求解、泰勒展开。

```python
import sympy as sp

x, y = sp.symbols("x y")
f = x**3 * sp.exp(x) + sp.sin(x)**2
print(sp.diff(f, x))                                    # 精确导数
print(sp.simplify(sp.diff(sp.sin(x) * sp.cos(x), x)))   # 化简 → cos(2x)
print(sp.solve(x**2 - 5*x + 6, x))                      # 解析解 [2, 3]
print(sp.series(sp.exp(x), x, 0, 4))                    # 泰勒：1 + x + x**2/2 + x**3/6 + O(x**4)
# ⚠️ 符号膨胀：中间表达式会指数级变大，大表达式先 sp.count_ops 看规模
print(sp.count_ops(sp.expand((x + y)**20)))             # 20 次幂展开 21 项 → 96 个操作
```

### 符号积分 (SymPy: integrate)——解析积分与校验；**积不出 ≠ 积分不存在**

`integrate` 积不出时常见原因是**无初等闭式**（多数积分本无初等闭式），sympy 会用 erf/erfi 等特殊函数表出——这是答案，不是失败。

```python
import sympy as sp

x = sp.symbols("x")
print(sp.integrate(sp.exp(-x**2), (x, -sp.oo, sp.oo)))  # sqrt(pi)：广义定积分可精确
print(sp.integrate(sp.exp(-x**2), x))                   # sqrt(pi)*erf(x)/2：特殊函数表出
print(sp.integrate(sp.exp(x**2), x))                    # sqrt(pi)*erfi(x)/2：无初等闭式 ≠ 不存在
# ⚠️ 符号结果数值代入前先 sp.simplify 化简；数值评估用 sp.N(expr, n)
print(sp.N(sp.integrate(sp.exp(-x**2), (x, 0, 1)), 10))
```

### 符号→数值桥 (lambdify)——符号推导出的公式编译成向量化 numpy 函数

推导（符号）与计算（数值）的分界线：先符号化简，再 lambdify，别在数值循环里反复调 sympy。

```python
import sympy as sp
import numpy as np

x, k = sp.symbols("x k")
expr = sp.sin(x) * sp.exp(-k * x) / x
f = sp.lambdify((x, k), expr, "numpy")     # 显式 "numpy" 钉死向量化后端（装了 numpy/scipy 时默认即向量化；
                                           # 无 numpy 的环境回退 math/cmath/mpmath，只吃标量——显式指定保证跨环境一致）
xs = np.linspace(0.5, 2.5, 5)
print(np.round(f(xs, 0.5), 4))
# ⚠️ 残留未赋值的 Symbol 要到数值调用时才报错——lambdify 后立刻用小数组试跑一次
# ⚠️ 典型用法：符号推导解析雅可比/闭式解 → lambdify 交给数值代码
```

### 微型前向自动微分 (Forward AD via Dual Numbers)——理解 AD 是什么：不是数值差分，也不是符号展开

对偶数 v + εd（ε²=0）让链式法则精确传播：每个基本算子同时算值和导数，得到**机器精度级**导数。前向模式一次算一个输入方向（JVP）。

```python
import math

class D:                                       # dual number：v + εd，d 是当前链式累积导数
    __slots__ = ("v", "d")
    def __init__(self, v, d=0.0):
        self.v, self.d = v, d
    def __add__(s, o):
        o = o if isinstance(o, D) else D(o)
        return D(s.v + o.v, s.d + o.d)
    __radd__ = __add__
    def __mul__(s, o):                         # 乘积法则：(uv)' = u'v + uv'
        o = o if isinstance(o, D) else D(o)
        return D(s.v * o.v, s.d * o.v + s.v * o.d)
    __rmul__ = __mul__

def d_sin(t):                                  # 基本算子：链式法则 sin' = cos * t'
    return D(math.sin(t.v), math.cos(t.v) * t.d)

x = D(1.5, 1.0)                                # 种子 d=1.0：对 x 求导
y = 3.0 * x * x + d_sin(x)
print(y.v, y.d, 6 * 1.5 + math.cos(1.5))       # 值 / AD 精确导数 / 手工验证一致
# ⚠️ AD 是机器精度级精确导数，但问题本身病态时梯度"精确而无用"——先看条件数再信梯度
```

### 反向模式即反向传播 + 梯度检验 (Reverse AD = Backprop, Gradient Check)——自定义梯度上线前的验收动作

反向模式一次反向扫描得到**全部**参数的梯度（VJP），计算量 ≈ 两次前向——这就是反向传播。**自定义层/自定义损失上线前必做有限差分对照**。

```python
import numpy as np

def loss(w):                        # 一个带"自定义梯度"的标量损失
    return float(np.sum(np.sin(w) * w))

def grad_analytic(w):               # 手工推导的梯度（假装是反向传播算出来的）
    return np.sin(w) + w * np.cos(w)

w = np.array([0.3, -1.2, 2.0])
eps = 1e-6                          # ⚠️ eps 太大截断误差大、太小舍入误差大，1e-5~1e-6 合适
I = np.eye(len(w))
g_num = np.array([(loss(w + eps * I[i]) - loss(w - eps * I[i])) / (2 * eps)
                  for i in range(len(w))])     # 中心差分（O(eps²) 精度）
rel = np.max(np.abs(grad_analytic(w) - g_num) / (np.abs(g_num) + 1e-8))
print(rel)   # 相对误差 ~1e-9 级 → 梯度正确
```

**陷阱规避写法**：eps 扫描看 U 形——别迷信"eps 越小越准"；比较用**相对容差**，别用 `==` 或纯绝对阈值。

```python
import numpy as np

def loss(w):
    return float(np.sum(np.sin(w) * w))

def grad(w):
    return np.sin(w) + w * np.cos(w)

w = np.array([0.3, -1.2, 2.0])
I = np.eye(len(w))
for eps in (1e-4, 1e-6, 1e-9):
    g_num = np.array([(loss(w + eps * I[i]) - loss(w - eps * I[i])) / (2 * eps)
                      for i in range(len(w))])
    rel = np.max(np.abs(grad(w) - g_num) / (np.abs(grad(w)) + 1e-8))  # ⚠️ 相对容差
    print(f"eps={eps:g} 相对误差={rel:.2e}")
# 典型 U 形：1e-4 截断误差主导 → 1e-6 最佳 → 1e-9 舍入误差回升
# ⚠️ 不可导点（ReLU 折点、argmax）与饱和激活处梯度检验天然失真，换随机多点重测
```

## 反模式（代码级翻车）

- ❌ `integrate` 没返回初等表达式就断言"积分不存在" → ✅ 无初等闭式 ≠ 积分不存在（erf/erfi/级数都是合法答案），数值场景直接 `sp.N` 或数值积分
- ❌ 符号推导完直接循环里反复调 sympy 求值 → ✅ `sp.simplify` 后 `lambdify(..., "numpy")` 一次编译，向量化计算
- ❌ lambdify 依赖环境默认后端（无 numpy 的环境回退 math/cmath/mpmath 只吃标量，传数组直接翻车）→ ✅ 显式 `lambdify(..., "numpy")` 钉死后端，落库前用小数组试跑一次
- ❌ 梯度检验用 `==` 或绝对阈值 `abs(a-b) < 1e-8` → ✅ 相对容差 `abs(a-b) <= atol + rtol*abs(b)`；eps 取 1e-5~1e-6 并多点随机重测
- ❌ AD 求导的函数里用 `if x > 0:` 数据分支 / 原地修改变量 → ✅ 保持计算图连续（`where`/掩码写法），分支与原地修改会悄悄制造错误计算图
- ❌ 大符号表达式一路 `expand` 到底 → ✅ 先 `sp.count_ops` 看规模，必要时 `sp.cse` 提公共子式、尽早 lambdify 退出符号域
