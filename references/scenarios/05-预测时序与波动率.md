# 🎯 scenario · 预测时序与波动率

> **问题信号**：
> - "预测一下未来 12 期的销量 / 价格 / 流量"
> - "未来波动率会有多大 / VaR 该设多少"
> - "这序列能直接建模吗，要先做什么检查"
> - "大波动总扎堆出现（波动率聚集），怎么建模"
> - "这两个指标谁领先谁 / 有没有领先滞后关系"
> - "动态 beta / 潜在趋势这种隐变量，要边来数据边估"
>
> **典型任务**：
> 1. 月度销量序列 ARIMA 定阶，输出未来 12 期预测值与预测区间
> 2. 用日收益率拟合 GARCH(1,1)，把 σ̂²_{t+1} 喂给 VaR 计算
> 3. 对冲比率随行情漂移，用状态空间模型 + 卡尔曼滤波在线估计动态 beta
>
> **主推组合**：**ARIMA（主）+ GARCH / 卡尔曼滤波（辅）** —— 时序问题拆三问："均值走到哪"归 ARIMA，"波动有多大"归 GARCH（条件方差），"隐状态边来边估"归卡尔曼滤波（状态空间）；三件套覆盖本场景全部问法，且都在 statsmodels 一条工具链里。
> **备选**：ADF + ACF/PACF（建模前体检，永远是第一步） / Granger 因果（问领先滞后而非预测值时） / SDE 与 Euler-Maruyama（要"一万条未来路径"而非点预测时） / 马尔可夫链（问 regime 状态切换时）

---

## 🥇 主推工具详解

### A. ARIMA（AR / MA / ARMA / ARIMA）

**为什么适配**："下期/未来 N 期是多少"的单变量预测默认起点。(p,d,q) 把"差分到平稳 + 自回归 + 滑动平均"流程化，AIC/BIC 扫描定阶不用拍脑袋，`.get_forecast()` 直接给预测均值加区间——基准模型里唯一一条龙的选择，也是一切花哨模型必须打赢的对手盘。

**一句话 / 输入输出**：用自身滞后（AR）与滞后噪声（MA）的线性组合建模平稳序列；ARIMA 先差分 d 次再建模，处理趋势非平稳。输入：历史序列 → 输出：阶数 (p,d,q)（AIC/BIC 定阶）+ 预测值与预测区间。

**陷阱**：
- 差分过度（d 过大）反而引入负单位根问题——d 由 ADF 检验与图形判断，多数经济/业务序列 d≤1；
- 拟合完必须过 Ljung-Box 残差白噪声检验：残差还有自相关 = 信息没提干净，预测区间不可信。

**代码入口**：`statsmodels.tsa.arima.model.ARIMA(endog, order=(p,d,q)).fit()` —— 拟合后 `.forecast(steps)` / `.get_forecast()` 出预测与区间；残差检验 `statsmodels.stats.diagnostic.acorr_ljungbox(resid, lags=[10])` → [recipes/09-时间序列建模.md](../recipes/09-时间序列建模.md)

**条目全文**：[domains/C-概率统计与随机/C6-时间序列.md](../domains/C-概率统计与随机/C6-时间序列.md)

### B. GARCH 族

**为什么适配**："波动率预测"问题的正解。收益率平方序列"大波动跟大波动"（聚集）是常态，任何常数方差的模型在这里全错；GARCH 把条件方差写成自身滞后与平方残差滞后的函数，σ̂²_{t+1} 直接喂给 VaR、期权定价输入与风险平价调仓频率。

**一句话 / 输入输出**：把条件方差建模为其自身滞后与平方残差滞后的函数，捕捉波动率聚集。输入：收益率序列 → 输出：条件方差预测 σ̂²_{t+1} 与参数 (ω, α, β)。

**陷阱**：
- 先定均值方程（常数或 ARMA）再拟合 GARCH——跳过这步，平方残差里混着均值结构，α、β 全是脏的；
- GARCH(1,1) 是默认起点，高阶易过拟合；拟合前先 `het_arch` 确认真有 ARCH 效应，别把白噪声硬拧成波动模型。

**代码入口**：ARCH 效应检验 `statsmodels.stats.diagnostic.het_arch(resid)`；均值方程 `ARIMA(endog, order=(p,0,q)).fit()`；GARCH 拟合本体在 `arch` 专用库（`arch_model(returns, mean="Constant", vol="GARCH", p=1, q=1).fit(disp="off")`，需 pip install arch）→ [recipes/09-时间序列建模.md](../recipes/09-时间序列建模.md)

**条目全文**：[domains/C-概率统计与随机/C6-时间序列.md](../domains/C-概率统计与随机/C6-时间序列.md)

### C. 状态空间模型与卡尔曼滤波（State-Space & Kalman Filter）

**为什么适配**："隐变量边来数据边估"（动态 beta、潜趋势、Nowcasting）只有状态空间路线能干净解决：一组状态方程 + 一组观测方程，线性高斯下卡尔曼滤波就是递推最优解，还顺带输出对数似然供 MLE 调噪声参数——回归给的是静态 beta，卡尔曼给的是会呼吸的 beta。

**一句话 / 输入输出**：把系统写成"隐状态演化 + 带噪观测"两组方程，卡尔曼滤波在线性高斯假设下递推最优状态估计。输入：状态方程 + 观测方程 → 输出：状态滤波均值/协方差与对数似然。

**陷阱**：
- 线性高斯是前提——明显非线性的系统换 EKF/UKF/粒子滤波，硬套线性滤波只会得到自信的错误答案；
- 过程/观测噪声 Q、R 设定不当滤波会发散：先核对两者量纲与比例，再怀疑实现。

**代码入口**：`statsmodels.tsa.statespace.structural.UnobservedComponents(y, level=True, trend=True).fit()` —— 潜趋势/局部水平模型自带卡尔曼滤波；自定义状态空间继承 `statsmodels.tsa.statespace.mlemodel.MLEModel` → [recipes/09-时间序列建模.md](../recipes/09-时间序列建模.md)

**条目全文**：[domains/C-概率统计与随机/C6-时间序列.md](../domains/C-概率统计与随机/C6-时间序列.md)

## 🥈 备选速览（何时升级为主推）

| 工具 | 一句话 | 何时用它当主推 |
|------|--------|---------------|
| 平稳性诊断：ADF + ACF/PACF | ADF 查单位根，ACF/PACF 定阶并暴露季节性 | 永远是第一步——没过体检的序列不配进 ARIMA：`statsmodels.tsa.stattools.adfuller(x)` + `acf/pacf(x, nlags=k)`；注意 ADF 小样本功效低，"没检出非平稳"≠平稳 |
| Granger 因果 | X 的滞后显著改善对 Y 的预测，称 X "Granger 引致" Y | 问的是"谁领先谁"的领先滞后结构而非预测值：`statsmodels.tsa.stattools.grangercausalitytests(data_2col, maxlag=k)`；只对平稳序列有意义，结论是预测因果、不是结构因果 |
| SDE 与 Euler-Maruyama（C5 随机过程） | 连续时间随机动态 dX=a dt + b dW 的离散模拟 | 要的是"一万条未来路径"（定价/压力情景/路径依赖）而非点预测：GBM 用精确格式 `X *= np.exp((mu-0.5*s2)*dt + s*np.sqrt(dt)*z)` 防越界 → [recipes/11-蒙特卡洛方法.md](../recipes/11-蒙特卡洛方法.md) |
| 马尔可夫链（C5 随机过程） | 未来只依赖当前态，由转移矩阵 P 驱动 | 问的是 regime 划分与切换（低/中/高波动状态）：`np.linalg.matrix_power(P, k)` 求 k 步概率，平稳分布取 `np.linalg.eig(P.T)` 特征值 1 的左特征向量并归一化；有吸收态的链会卡死 |

## ⚠️ 本场景翻车清单

- ❌ 拿价格（非平稳）直接 ARMA/回归 → 伪回归，R² 虚高、t 统计量失效；先 `adfuller` 查单位根，非平稳就差分或改用收益率建模。
- ❌ ADF p 值 > 0.05 就宣布"序列平稳" → ADF 小样本下功效低，"没检出非平稳"≠平稳；配合 ACF 拖尾形态与业务常识双确认。
- ❌ 追求"更平"把差分 d 拉到 2、3 → 差分过度引入负单位根，序列反而更难建模；d 由 ADF 与图形定，多数序列 d≤1。
- ❌ 拟合完直接 `.forecast()`，不看残差 → 残差还有自相关说明信息没提干净，预测区间系统性偏窄；`acorr_ljungbox` 过一遍再出报告。
- ❌ 收益率波动明显扎堆还硬套同方差模型，或一步上 GARCH(3,3) → 先 `het_arch` 查 ARCH 效应；GARCH(1,1) 是默认起点，且必须先定均值方程再拟合。
- ❌ 卡尔曼滤波结果漂移/发散就怀疑代码 → 多半是 Q、R 噪声设定错（量纲、比例）；先核对噪声协方差，明显非线性再换 EKF/粒子滤波。
